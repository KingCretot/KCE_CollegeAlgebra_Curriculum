Let's Begin

The equation that starts everything

Almost every problem in College Algebra eventually comes down to solving a linear equation. Quadratics get factored into linear pieces, absolute value splits into two linear equations, and word problems turn into one. If this step is automatic, everything after it gets easier.

Today you'll solve linear equations with fractions and decimals, decide whether an equation has one solution, every solution, or none, and solve a formula for any letter in it.

By the end of today, you will be able to:

  • 1Use the addition and multiplication properties of equality to solve linear equations, including ones with fractions and decimals
  • 2Classify an equation as conditional, an identity, or a contradiction
  • 3Solve a formula for a specified variable

Vocabulary

The language of equations

Equivalent Equations

Equations with the same solution set. Solving an equation means rewriting it as simpler and simpler equivalent equations until the variable is alone.

💡Example: 4x − 3 = 2x + 9, 2x = 12, and x = 6 are equivalent: each has solution set {6}.
Properties of Equality

Addition property: if a = b, then a + c = b + c. Multiplication property: if a = b and c ≠ 0, then ac = bc. Either move produces an equivalent equation.

💡Remember: adding or subtracting the same number on both sides is the addition property; multiplying or dividing both sides by the same nonzero number is the multiplication property.
Conditional, Identity, Contradiction

A conditional equation is true for some values only (x + 1 = 5 has solution set {4}). An identity is true for every real number; solving it ends in a true statement like 0 = 0. A contradiction is never true; solving it ends in a false statement like 0 = 5, and its solution set is ∅.

💡Write it: identity → {all real numbers}; contradiction → ∅.
Literal Equation

A formula with several letters, such as A = P(1 + rt). Solving for a specified variable means getting that one letter alone on one side.

💡Tip: treat every other letter exactly like a number.

How It Works

A reliable order of steps

1
Clear fractions or decimals
Multiply every term on both sides by the LCD (or by 10, 100, …).
2
Distribute and combine
Remove parentheses, then combine like terms on each side.
3
Collect and isolate
Get variable terms on one side and constants on the other, then divide by the coefficient.
4
Check and classify
Substitute your answer into the original equation. If the variable disappeared, decide: true statement = identity, false = contradiction.

💭 Notice: Multiplying by the LCD is legal only if you multiply every term, including terms that aren't fractions.

Real-World Context

Formulas you rearrange on the job

Nurses rearrange dosage formulas, accountants rearrange interest formulas, and engineers rearrange physics formulas — always solving for whatever is unknown.

Example: Simple interest: A = P(1 + rt). To find how long money must sit to grow to A, solve for t: t = (A − P)/(Pr).

Worked Example · Fractions

Clearing fractions with the LCD

Goal: Solve (x + 3)/4 + (x − 1)/6 = 2.

1
Multiply by the LCD, 12
3(x + 3) + 2(x − 1) = 24
2
Distribute and combine
3x + 9 + 2x − 2 = 24 → 5x + 7 = 24
3
Isolate x
5x = 17 → x = 17/5
4
Check
(17/5 + 3)/4 = 8/5 and (17/5 − 1)/6 = 2/5; 8/5 + 2/5 = 2 ✓. Solution set {17/5}.

Worked Example · Specified Variable

Solve A = P(1 + rt) for t

Goal: Get t alone.

1
Distribute
A = P + Prt
2
Subtract P
A − P = Prt
3
Divide by Pr
t = (A − P)/(Pr)

💭 Notice: Classifying: 3(x − 2) + 5 = 3x − 1 simplifies to 3x − 1 = 3x − 1, then 0 = 0. That's an identity — every real number works.

Your Turn — Guided Practice

Now you try, with me right here

Solve and classify.

Question 1: 2(x + 1) = 2x + 5

Here's why: 2x + 2 = 2x + 5 becomes 2 = 5, which is false. No value works, so it's a contradiction with solution set ∅.

Question 2: 4x − 3 = 2x + 9

Here's why: Subtract 2x: 2x − 3 = 9. Add 3: 2x = 12, so x = 6. Check: 4(6) − 3 = 21 and 2(6) + 9 = 21 ✓ The solution set is {6}. {3} comes from dividing 12 by 4 instead of by 2.

Mini Knowledge Test

Show what you know: 5 quick questions

Question 1
Solve 5(x − 2) − 3 = 2x + 8.
Here's why: Distribute: 5x − 10 − 3 = 2x + 8, so 5x − 13 = 2x + 8. Subtract 2x: 3x − 13 = 8. Add 13: 3x = 21, x = 7. Check: 5(5) − 3 = 22 and 2(7) + 8 = 22 ✓ The solution set is {7}.
Question 2
Solve x/3 − 2 = x/5.
Here's why: Multiply every term by 15: 5x − 30 = 3x. Then 2x = 30 and x = 15. Check: 5 − 2 = 3 and 15/5 = 3 ✓ The solution set is {15}.
Question 3
Classify 4(x + 1) − x = 3x + 4.
Here's why: The left side simplifies to 3x + 4, the same as the right. Solving gives 0 = 0, a true statement, so every real number is a solution.
Question 4
Solve P = 2l + 2w for w.
Here's why: Subtract 2l: P − 2l = 2w. Divide the whole side by 2: w = (P − 2l)/2, which can also be written P/2 − l.
Question 5
Solve 0.06x + 0.09(15 − x) = 0.07(15).
Here's why: Multiply by 100: 6x + 9(15 − x) = 7(15). Then 6x + 135 − 9x = 105, so −3x = −30 and x = 10. The solution set is {10}.
