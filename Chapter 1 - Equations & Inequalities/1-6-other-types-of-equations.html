Let's Begin

Equations that can fool you

Some equations produce answers that look right but don't actually work. Clearing denominators or squaring both sides can create these extraneous solutions. In this lesson, checking your answers is part of solving the equation.

Today you'll solve rational, radical, rational-exponent, and quadratic-in-form equations, plus work-rate problems.

By the end of today, you will be able to:

  • 1Solve rational equations and identify excluded values
  • 2Solve radical equations and equations with rational exponents, checking for extraneous solutions
  • 3Solve equations quadratic in form and work-rate problems

Vocabulary

Two things to watch

Excluded Values

Any value that makes a denominator 0 can't be a solution. List these before you solve a rational equation.

💡Example: in 3/(x − 2), x ≠ 2.
Extraneous Solution

A value that comes out of the algebra but doesn't satisfy the original equation. Squaring both sides and multiplying by a variable expression can create them.

💡Rule: check every solution in the original equation.

How It Works

Methods by type

1
Rational
Note excluded values, multiply by the LCD, solve, and reject any excluded value.
2
Radical
Isolate the radical, raise both sides to the index power, solve, and check every answer.
3
Quadratic in form
If the equation looks like a(u)² + b(u) + c = 0 for some expression u, substitute, solve for u, then solve for x.
4
Work rate
If a job takes t hours alone, the rate is 1/t of the job per hour. Rates add when people work together.

💭 Notice: x⁴ − 13x² + 36 = 0: let u = x². Then u² − 13u + 36 = 0 gives u = 4 or 9, so x = ±2 or ±3 — four solutions.

Real-World Context

Where these show up

Work-rate equations plan how long a team will take on a job; radical equations appear in physics formulas like the period of a pendulum.

Example: Pipe A fills a tank in 6 hours and pipe B in 3 hours. Together: 1/6 + 1/3 = 1/2 of the tank per hour, so 2 hours.

Worked Example · Rational

An answer that has to be rejected

Goal: Solve x/(x − 3) = 3/(x − 3) + 2.

1
Excluded value
x ≠ 3
2
Multiply by (x − 3)
x = 3 + 2(x − 3)
3
Solve
x = 3 + 2x − 6 → x = 3
4
Reject
3 is excluded, so there is no solution: ∅.

Worked Example · Radical

√(x + 7) + 5 = x

Goal: Solve and check.

1
Isolate the radical
√(x + 7) = x − 5
2
Square both sides
x + 7 = x² − 10x + 25 → x² − 11x + 18 = 0
3
Solve
(x − 9)(x − 2) = 0 → x = 9 or 2
4
Check
x = 9: √16 + 5 = 9 ✓. x = 2: √9 + 5 = 8 ≠ 2 ✗. Solution set {9}.

Your Turn — Guided Practice

Now you try, with me right here

Solve.

Question 1 — x^(2/3) = 4

Here's why: Rewrite as (x^(1/3))² = 4, so x^(1/3) = ±2. Cubing gives x = ±8. Check: (−8)^(2/3) = (−2)² = 4 ✓

Question 2 — Jada paints a room in 4 hours and Malik in 6 hours. How long together?

Here's why: 1/4 + 1/6 = 5/12 of the room per hour, so the time is 12/5 = 2.4 hours. Averaging the times (5 hours) is the classic mistake.

Mini Knowledge Test

Show what you know — 5 quick questions

Question 1
Solve 2/x + 1/3 = 1.
Here's why: Multiply by 3x: 6 + x = 3x → 6 = 2x → x = 3. Check: 2/3 + 1/3 = 1 ✓
Question 2
Solve √(2x + 3) = x.
Here's why: Square: 2x + 3 = x² → x² − 2x − 3 = 0 → x = 3 or −1. Check −1: √1 = 1, not −1, so it's extraneous. Only 3 works.
Question 3
Solve x⁴ − 5x² + 4 = 0.
Here's why: Let u = x²: u² − 5u + 4 = 0 → u = 1 or 4. Then x² = 1 or 4, so x = ±1 or ±2. {1, 4} stops at u.
Question 4
One printer finishes a job in 3 hours and another in 6 hours. How long working together?
Here's why: Rates add: 1/3 + 1/6 = 1/2 job per hour, so the job takes 2 hours. It must be faster than the faster printer alone.
Question 5
Solve (x + 1)/(x − 2) = 3/(x − 2).
Here's why: Multiplying by (x − 2) gives x + 1 = 3, so x = 2. But 2 is excluded, so the solution set is ∅.
