Let's Begin

Absolute value means distance

|x| is the distance from x to 0 on a number line. So |x| = 3 means x is 3 units from 0, which happens at 3 and at −3. Thinking of distance turns every absolute value problem into one of three patterns.

Today you'll solve absolute value equations and inequalities and handle the special cases where the answer is everything or nothing.

By the end of today, you will be able to:

  • 1Solve absolute value equations, including |a| = |b|
  • 2Solve |expression| < k and |expression| > k, isolating the absolute value first
  • 3Recognize the special cases with zero or a negative number

Vocabulary

The three patterns (k > 0)

Equal and Less Than

|u| = k → u = k or u = −k. |u| < k → −k < u < k (a single interval, "between").

💡Memory hook: less than → "less-thAND", one interval.
Greater Than and Special Cases

|u| > k → u < −k or u > k (two separate pieces). If k < 0: |u| = k and |u| < k have no solution; |u| > k is true for all real numbers.

💡Example: |2x − 5| ≥ −3 is true for every x, since absolute value is never negative.

How It Works

Solving steps

1
Isolate the absolute value
Get |u| alone on one side first.
2
Check the sign of k
If k is negative, use the special cases.
3
Rewrite without bars
Equal → two equations. Less than → three-part. Greater than → two inequalities joined by "or."
4
Solve and write the answer
Use interval notation; greater-than answers use ∪.

💭 Notice: |u| = |w| means u and w are the same distance from 0, so u = w or u = −w.

How It Works · Special Cases

When k is 0 or negative

1
k = 0, equal
|u| = 0 only when u = 0. Example: |x + 5| = 0 gives x = −5, so the solution set is {−5}.
2
k = 0, less than
|u| < 0 is never true: ∅. But |u| ≤ 0 is true only when |u| = 0, so solve u = 0. Example: |2x − 6| ≤ 0 → 2x − 6 = 0 → {3}.
3
k = 0, greater than
|u| > 0 is true for every x except where u = 0. Example: |x − 4| > 0 → (−∞, 4) ∪ (4, ∞). (And |u| ≥ 0 is true for all real numbers.)
4
k negative
|u| = k, |u| < k, and |u| ≤ k have solution set ∅. |u| > k and |u| ≥ k are true for all real numbers, (−∞, ∞). Example: |8x − 9| < −8 → ∅; |9x + 5| > −2 → (−∞, ∞).

💭 Notice: Check k only after the absolute value is alone. In |4x − 7| + 3 = 1, the real right side is 1 − 3 = −2, so the equation has no solution.

Real-World Context

Tolerances

Manufacturing specs use absolute value: a part must be within a tolerance of its target size.

Example: A bolt must be 20 mm long, within 0.05 mm: |L − 20| ≤ 0.05, so 19.95 ≤ L ≤ 20.05.

Goal: Solve.

x = 5 or x = −2

{−2, 5}

Worked Example · Greater Than

|9 − 8x| > 4

Goal: Solve and write in interval notation.

1
Two pieces
9 − 8x > 4 or 9 − 8x < −4
2
First piece
−8x > −5 → x < 5/8 (flip)
3
Second piece
−8x < −13 → x > 13/8 (flip)
4
Answer
(−∞, 5/8) ∪ (13/8, ∞)
Open circles at 5/8 and 13/8

Worked Example · Isolate First

2|x − 1| + 3 > 9

Goal: Solve and write in interval notation.

1
Isolate the absolute value
Subtract 3: 2|x − 1| > 6. Divide by 2: |x − 1| > 3
2
Two pieces
x − 1 < −3 or x − 1 > 3
3
Solve each
x < −2 or x > 4
4
Answer
(−∞, −2) ∪ (4, ∞)
(−∞, −2) ∪ (4, ∞): open circles at −2 and 4, shaded outward

💭 Common slip: Do not split into two pieces before isolating. Writing 2|x − 1| + 3 > 9 as 2(x − 1) + 3 > 9 or 2(x − 1) + 3 < −9 gives the wrong boundary, x < −5, on the left side.

Your Turn · Guided Practice, Part 2

Special cases and more practice

Solve. Isolate the absolute value and check the sign of k first.

Question 3: |2x + 2| = 1

Here's why: 2x + 2 = 1 gives x = −1/2, and 2x + 2 = −1 gives x = −3/2. The solution set is {−3/2, −1/2}. {−1/2} forgets the negative case.

Question 4: |8x − 9| < −8

Here's why: An absolute value is never negative, so it can never be less than −8. The solution set is ∅. (1/8, 17/8) is the answer to |8x − 9| < 8, which ignores the negative sign on k.

Question 5: |9x + 5| > −2

Here's why: Every absolute value is 0 or more, and 0 > −2, so every real number works: (−∞, ∞). ∅ is the answer for < a negative number, not >.

Question 6: |2x − 6| ≤ 0

Here's why: An absolute value can be ≤ 0 only if it equals 0. So 2x − 6 = 0 and x = 3: the solution set is {3}. ∅ would be the answer to |2x − 6| < 0.

Question 7: |x − 4| > 0

Here's why: |x − 4| is positive for every x except x = 4, where it equals 0. So the solution set is every real number except 4: (−∞, 4) ∪ (4, ∞). (−∞, ∞) forgets that 0 > 0 is false.

Mini Knowledge Test

Show what you know: 8 quick questions

Question 1
Solve |x − 4| = 9.
Here's why: x − 4 = 9 gives 13; x − 4 = −9 gives −5. Forgetting the negative case drops −5.
Question 2
Solve |2x + 1| < 7.
Here's why: −7 < 2x + 1 < 7 → −8 < 2x < 6 → −4 < x < 3. Strict, so parentheses.
Question 3
Solve |x − 3| ≥ 2.
Here's why: Greater than → two pieces: x − 3 ≤ −2 gives x ≤ 1, and x − 3 ≥ 2 gives x ≥ 5. [1, 5] is the answer to the ≤ version.
Question 4
Solve |4x − 7| + 3 = 1.
Here's why: Isolate first: |4x − 7| = −2. Absolute value can't be negative, so the solution set is ∅.
Question 5
Solve |3x − 2| = |x + 6|.
Here's why: 3x − 2 = x + 6 gives x = 4. 3x − 2 = −(x + 6) gives 4x = −4, x = −1. Check x = −1: |−5| = |5| ✓
Question 6
Solve |3x + 6| = |4x + 9|.
Here's why: Case 1: 3x + 6 = 4x + 9 gives x = −3. Case 2: 3x + 6 = −(4x + 9) = −4x − 9 gives 7x = −15, x = −15/7. Check x = −15/7: |−3/7| = |3/7| ✓. {−3} drops the second case, 3/7 comes from writing −(4x + 9) as −4x + 9, and 3 is a sign slip in case 1.
Question 7
Solve |−9 − 8x| > 4.
Here's why: Two pieces: −9 − 8x > 4 gives −8x > 13, so x < −13/8 (flip). −9 − 8x < −4 gives −8x < 5, so x > −5/8 (flip). Strict >, so parentheses. (−13/8, −5/8) is the answer to the < version, (−∞, 5/8) ∪ (13/8, ∞) is the answer for |9 − 8x| > 4, and brackets would include the endpoints.
Question 8
Solve |4x − 1| − 6 < 1.
Here's why: Isolate first: |4x − 1| < 7. Then −7 < 4x − 1 < 7, so −6 < 4x < 8 and −3/2 < x < 2. (0, 1/2) drops the −6 and solves |4x − 1| < 1, (−5/4, 7/4) solves |4x − 1| < 6, and the union is the answer to the > version.
