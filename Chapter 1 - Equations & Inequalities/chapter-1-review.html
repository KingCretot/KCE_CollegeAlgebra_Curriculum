Key Ideas · Lessons 1.1–1.2

Linear equations and applications

Lesson 1.1

Solve, then classify

Clear fractions with the LCD, distribute, collect, isolate, check. If the variable cancels: a true statement means an identity (all real numbers); a false one means a contradiction (∅). To solve for a specified variable, treat the other letters like numbers.

Example: A = P(1 + rt) → t = (A − P)/(Pr)
Lesson 1.2

Translate, then solve

Name the unknown, express the other quantities with it, write the equation from a formula or a total, solve, and check against the words. Key formulas: d = rt, I = Prt, pure amount = total × concentration.

Example: 0.2x + 0.5(10) = 0.3(x + 10) → x = 20 L

Key Ideas · Lessons 1.3–1.5

Complex numbers and quadratics

Lesson 1.3

Complex numbers

i² = −1. Rewrite √(negative) as i√ before multiplying. Multiply with FOIL and replace i² with −1. Divide by multiplying by the conjugate. Powers of i cycle every 4: i, −1, −i, 1.

Example: (4 + 2i)/(1 + i) = 3 − i
Lesson 1.4

Four methods and the discriminant

Factoring, square root property, completing the square, quadratic formula x = [−b ± √(b² − 4ac)]/(2a). Discriminant b² − 4ac: positive → two real, zero → one real, negative → two nonreal complex.

Example: 2x² + 3x + 5: 9 − 40 < 0, two nonreal solutions
Lesson 1.5

Applications

Area, a² + b² = c², and projectile height s = −16t² + v₀t + s₀. Reject negative lengths and times.

Example: −16t² + 64t = 0 → lands at t = 4 s

Key Ideas · Lessons 1.6–1.8

Other equations and inequalities

Lesson 1.6

Check for extraneous solutions

Rational: list excluded values first. Radical: isolate, raise both sides to a power, check every answer. Quadratic in form: substitute u. Work: rates (1/t) add.

Example: √(2x + 3) = x gives 3 and −1; only 3 checks
Lesson 1.7

Inequalities in interval notation

Flip the symbol when multiplying or dividing by a negative. Quadratic and rational inequalities: find critical values, test each interval. Never include a value that zeros a denominator.

Example: (x + 3)/(x − 1) ≤ 0 → [−3, 1)
Lesson 1.8

Absolute value

|u| = k → u = ±k. |u| < k → −k < u < k. |u| > k → u < −k or u > k. Isolate the bars first; a negative k means no solution (or all reals for >).

Example: |9 − 8x| > 4 → (−∞, 5/8) ∪ (13/8, ∞)

Practice Test

10 questions, every lesson mixed together

Just like a unit test, these jump between lessons. You get two tries on each question, and every question explains itself after you answer.

Question 1
Solve (x + 2)/3 − x/4 = 1.
Here's why: Multiply by 12: 4(x + 2) − 3x = 12 → 4x + 8 − 3x = 12 → x = 4. Check: 6/3 − 4/4 = 2 − 1 = 1 ✓
Question 2
How many liters of pure water must be added to 12 L of a 25% salt solution to dilute it to 20%?
Here's why: Pure water adds no salt: 0.25(12) = 0.20(12 + x) → 3 = 2.4 + 0.2x → x = 3. Check: 3 L of salt in 15 L is 20% ✓
Question 3
Write (3 − 2i)² in a + bi form.
Here's why: (3 − 2i)² = 9 − 12i + 4i² = 9 − 12i − 4 = 5 − 12i. 13 − 12i treats i² as +1.
Question 4
Solve x² − 4x + 13 = 0.
Here's why: x = [4 ± √(16 − 52)]/2 = [4 ± √−36]/2 = (4 ± 6i)/2 = 2 ± 3i.
Question 5
A rectangle's length is 3 cm more than its width, and its area is 40 cm². What is the width?
Here's why: w(w + 3) = 40 → w² + 3w − 40 = 0 → (w + 8)(w − 5) = 0. Width can't be negative, so w = 5 (length 8).
Question 6
Solve √(x + 2) = x − 4.
Here's why: Square: x + 2 = x² − 8x + 16 → x² − 9x + 14 = 0 → x = 2 or 7. Check 2: √4 = 2 but 2 − 4 = −2 ✗. Check 7: √9 = 3 = 7 − 4 ✓
Question 7
Solve x⁴ − 10x² + 9 = 0.
Here's why: Let u = x²: u² − 10u + 9 = 0 → u = 1 or 9 → x = ±1 or ±3.
Question 8
Solve x² − 2x − 15 ≤ 0.
Here's why: (x − 5)(x + 3) ≤ 0. Testing x = 0 gives −15 ≤ 0 ✓, so the middle interval works, endpoints included.
Question 9
Solve (2x − 1)/(x + 3) > 0.
Here's why: Critical values −3 and 1/2. Testing x = 0 gives −1/3 < 0, so the middle fails; the outer intervals work. Strict >, and −3 zeros the denominator, so parentheses on both.
Question 10
Solve |5 − 2x| ≤ 9.
Here's why: −9 ≤ 5 − 2x ≤ 9 → −14 ≤ −2x ≤ 4 → divide by −2 and flip: 7 ≥ x ≥ −2, so [−2, 7].
