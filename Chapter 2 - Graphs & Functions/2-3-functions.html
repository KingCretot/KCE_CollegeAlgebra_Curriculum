Let's Begin

One input, exactly one output

A function is a rule that gives exactly one output for every input. A vending machine works this way: press B4 and you always get the same snack. If B4 sometimes gave chips and sometimes gave cookies, the machine would be broken. A relation that gives two outputs for one input is not a function.

Today you'll decide whether a relation is a function, find its domain and range, and work with function notation f(x).

By the end of today, you will be able to:

  • 1Decide whether a set of ordered pairs or a graph is a function (vertical line test)
  • 2Find the domain and range from ordered pairs, a graph, or an equation
  • 3Evaluate f(a), f(−x), and values read from a graph, and rewrite an equation in function notation

Vocabulary

The words for this lesson

Relation and Function

A relation is any set of ordered pairs (x, y). A function is a relation in which each x-value is paired with exactly one y-value.

💡Memory hook: x-values may not repeat with different y-values. Repeated y-values are fine.
Domain and Range

The domain is the set of all inputs (x-values). The range is the set of all outputs (y-values).

💡Memory hook: Domain reads left to right on a graph; range reads bottom to top.
Function Notation

f(x) is read "f of x" and means the output of f when the input is x. It does not mean f times x.

💡Example: If f(x) = 3x − 1, then f(4) = 3(4) − 1 = 11.
Vertical Line Test

A graph is a function if no vertical line crosses it more than once.

💡Memory hook: A vertical line is one x-value. Crossing twice means two y-values for that x.
Increasing, Decreasing, Constant

Reading left to right, a function is increasing where the graph rises, decreasing where it falls, and constant where it is flat. These are stated as x-intervals.

💡Example: y = x² decreases on (−∞, 0) and increases on (0, ∞).

How It Works

Four skills, four moves

1
Is it a function?
Ordered pairs: look for an x-value that repeats with a different y-value. Graph: slide a vertical line across.
2
Domain
List every x-value, or read the graph from left to right. Watch for open and closed endpoints and arrows.
3
Range
List every y-value, or read the graph from bottom to top.
4
Evaluate
Replace every x with the input inside parentheses, then simplify. To rewrite an equation as f(x), solve for y and replace y with f(x).

💭 Notice: f(−2) means put −2 in for x. Square it as (−2)² = 4, not −2² = −4.

Real-World Context

Functions are everywhere a price is set

At a gas station, the cost depends on how many gallons you pump. Each number of gallons gives exactly one cost, so cost is a function of gallons.

Example: At $3.50 per gallon, C(g) = 3.50g. Then C(10) = 35, so 10 gallons cost $35. The domain is g ≥ 0, since you can't pump negative gallons.

Worked Example · Ordered Pairs

Function or not? Domain and range

Goal: Decide whether each relation is a function, then give its domain and range.

1
Relation A
{(−4, 1), (−3, −6), (3, −5), (3, 6)}
2
Check the x-values
x = 3 is paired with −5 and with 6. One input, two outputs: not a function.
3
Domain and range of A
Domain {−4, −3, 3} · Range {−6, −5, 1, 6}. List each value once.
4
Relation B
{(1, 8), (−1, −9), (−6, −5), (4, −9)}: every x is different, so it is a function. The y-value −9 repeats, and that's allowed. Domain {−6, −1, 1, 4} · Range {−9, −5, 8}.

Worked Example · Graphs

The vertical line test

Slide a vertical line (red, dashed) across each graph.

y = x² − 2: every vertical line hits once. Function.
x = y² − 2: the line hits twice. Not a function.
1
Domain and range of y = x² − 2
The graph runs forever left and right: domain (−∞, ∞). Its lowest point is y = −2: range [−2, ∞).
2
Reading f from the graph
For f(x) = x² − 2, find f(−1): go to x = −1, read the height of the graph. The point is (−1, −1), so f(−1) = −1.

Worked Example · Notation

Evaluating f(a) and f(−x)

Goal: Evaluate carefully with parentheses.

1
f(x) = 5x² + 5x + 3, find f(−2)
5(−2)² + 5(−2) + 3 = 5(4) − 10 + 3 = 13
2
f(x) = −2x² − 5x + 2, find f(−x)
Replace each x with (−x): −2(−x)² − 5(−x) + 2
3
Simplify
(−x)² = x², and −5(−x) = +5x, so f(−x) = −2x² + 5x + 2

Worked Example · Rewriting

From an equation to f(x)

Goal: Write x − 2y = 16 using function notation, then find f(4).

1
Solve for y
−2y = −x + 16
2
Divide by −2
y = ½x − 8
3
Replace y with f(x)
f(x) = ½x − 8
4
Evaluate
f(4) = ½(4) − 8 = 2 − 8 = −6

💭 Notice: dividing by −2 changes the sign of every term: −x becomes +½x and 16 becomes −8.

Your Turn — Guided Practice

Now you try, with me right here

Work each one, then tap your answer.

Question 1 — Is {(2, 5), (3, 5), (4, 5)} a function?

Here's why: Each x-value (2, 3, 4) appears once. All the outputs are 5, and repeated outputs are allowed. It's a function.

Question 2 — f(x) = x² − 3x − 6. Find f(4).

Here's why: f(4) = 4² − 3(4) − 6 = 16 − 12 − 6 = −2. (Getting −10 usually means 4² was computed as 4 · 2 = 8.)

Why This Matters

Functions are the language of the rest of the course

From here on, almost everything in College Algebra is a function: lines, parabolas, polynomials, exponentials, logarithms. Function notation is how you talk about them.

This shows up everywhere

  • Graphs of basic functions and piecewise functions (Lesson 2.6).
  • Shifting and reflecting graphs (Lesson 2.7).
  • Any formula where one quantity depends on another, like cost, distance, or temperature.

Mini Knowledge Test

Show what you know — 5 quick questions

Question 1
Which relation is not a function?
Here's why: The input 5 goes to both 1 and −1. The other relations repeat only outputs, which is allowed.
Question 2
Give the domain of {(1, 8), (−1, −9), (−6, −5), (4, −9)}.
Here's why: The domain is the set of x-values: 1, −1, −6, 4. {−9, −5, 8} is the range.
Question 3
If f(x) = 5x² + 5x + 3, what is f(−2)?
Here's why: 5(−2)² = 20, 5(−2) = −10, so 20 − 10 + 3 = 13. Getting 33 means −10 was treated as +10; −27 means (−2)² was treated as −4.
Question 4
If f(x) = −2x² − 5x + 2, what is f(−x)?
Here's why: (−x)² = x², so the first term stays −2x². −5(−x) = +5x. The constant 2 does not change.
Question 5
Write 3x + 2y = 8 in function notation.
Here's why: 2y = −3x + 8, then divide every term by 2: y = −(3/2)x + 4. Dividing only the x-term by 2 gives the wrong constant.
