Let's Begin

Steady change makes a straight line

When a quantity changes by the same amount every step, its graph is a straight line. Slope measures that steady change: how much y moves for each 1 unit x moves. A taxi that charges $2.50 per mile on top of a $3 base fare is a linear function with slope 2.5.

Today you'll graph linear functions, compute slope, recognize horizontal and vertical lines, and read slope as a rate of change.

By the end of today, you will be able to:

  • 1Graph a linear function f(x) = ax + b or a standard-form line Ax + By = C using intercepts, or using a point and the slope
  • 2Find the slope of a line through two points
  • 3Interpret slope as an average rate of change, including horizontal and vertical lines, and build cost, revenue, and profit models

Vocabulary

The words for this lesson

Linear Function

f(x) = ax + b, where a and b are real numbers. Its graph is a straight line; a is the slope and (0, b) is the y-intercept.

💡Example: f(x) = −2x + 4 has slope −2 and y-intercept (0, 4).
Slope

m = (y₂ − y₁)/(x₂ − x₁), the change in y divided by the change in x ("rise over run").

💡Memory hook: y on top. Keep the points in the same order in the top and bottom.
Horizontal and Vertical Lines

y = b is horizontal, slope 0, and is a function. x = a is vertical, slope undefined, and is not a function.

💡Memory hook: HOY: Horizontal, 0 slope, y = · VUX: Vertical, Undefined, x = .
Average Rate of Change

For a line, the slope tells how fast y changes per unit of x, in the problem's units.

💡Example: slope 80 people per year means the population grows by 80 each year.
Standard Form and Break-Even

A linear equation in standard form is Ax + By = C (A, B not both 0); its graph is a line. In a business model, cost C(x), revenue R(x), and profit P(x) = R(x) − C(x); the break-even point is where R(x) = C(x).

💡Example: 3x + 2y = 6 has intercepts (2, 0) and (0, 3).

How It Works

Graphing a line two ways

1
Intercepts
Set y = 0 to get the x-intercept and x = 0 to get the y-intercept. Plot both and draw the line.
2
Slope and a point
Plot the y-intercept, then use rise/run to find a second point.
3
Check the direction
Positive slope rises left to right, negative slope falls, zero slope is flat.
4
Special cases
If the line goes through the origin, both intercepts are (0, 0); use the slope for a second point.

💭 Notice: a 0 in the numerator gives slope 0 (horizontal). A 0 in the denominator gives an undefined slope (vertical).

Real-World Context

Slope is a rate

Any time you see "per," you are looking at a slope: dollars per hour, miles per gallon, people per year.

Example: A town had 1,200 residents in 2010 and 2,000 in 2020. Average rate of change: (2,000 − 1,200)/(2020 − 2010) = 80 residents per year.

Worked Example · Graphing

f(x) = −2x + 4

Goal: Graph using intercepts.

1
x-intercept
0 = −2x + 4 → x = 2. Point (2, 0).
2
y-intercept
f(0) = 4. Point (0, 4).
3
Draw
Connect the points. The slope −2 means the line falls 2 for every 1 to the right.
f(x) = −2x + 4: intercepts (2, 0) and (0, 4)

Worked Example · Point and Slope

Graph from a point and a slope

Goal: Graph the line through (−1, 5) with slope −4/3, and write it in standard form.

1
Plot the point
Start at (−1, 5).
2
Use rise over run
Slope −4/3 = −4 over 3: go down 4 and right 3 to reach (2, 1). Repeat to get (5, −3).
3
Draw the line
Connect the points and extend both ways.
4
Standard form Ax + By = C
y − 5 = −(4/3)(x + 1). Multiply by 3: 3y − 15 = −4x − 4, so 4x + 3y = 11. Check (2, 1): 8 + 3 = 11 ✓
Through (−1, 5), slope −4/3: down 4, right 3

Worked Example · Slope

Through (−2, 6) and (4, −3)

1
Change in y
−3 − 6 = −9
2
Change in x
4 − (−2) = 6
3
Slope
m = −9/6 = −3/2. The line falls 3 for every 2 to the right.

💭 Common slip: subtracting y in one order and x in the other order flips the sign. Pick one point to go first and keep it first.

Worked Example · Special Lines

Horizontal and vertical

1
y = 3
Every point has y = 3. Slope 0. It is a constant function.
2
x = −2
Every point has x = −2. The run is 0, so the slope is undefined. It fails the vertical line test, so it is not a function.
y = 3: horizontal, slope 0
x = −2: vertical, slope undefined

Worked Example · Cost, Revenue, Profit

Linear models and break-even

Goal: A company makes T-shirts. Fixed costs are $1,200, each shirt costs $6 to make, and each sells for $14. Write the cost, revenue, and profit functions and find the break-even point.

1
Cost
Fixed cost plus cost per item: C(x) = 6x + 1200, where x is the number of shirts.
2
Revenue
Price times number sold: R(x) = 14x.
3
Profit
Profit is revenue minus cost: P(x) = 14x − (6x + 1200) = 8x − 1200.
4
Break-even
Set R(x) = C(x): 14x = 6x + 1200, so 8x = 1200 and x = 150 shirts. Fewer than 150 is a loss; more is a profit. For example, P(200) = 1600 − 1200 = $400.

💭 Notice: subtract the whole cost function in parentheses. 14x − 6x + 1200 is a sign slip: the 1200 must be subtracted too.

Your Turn — Guided Practice

Now you try, with me right here

Work each one, then tap your answer.

Question 1 — Find the slope through (1, 2) and (4, 11).

Here's why: (11 − 2)/(4 − 1) = 9/3 = 3. 1/3 puts the x-change on top.

Question 2 — What is the slope of x = 5?

Here's why: x = 5 is a vertical line. Any two points have the same x, so the denominator x₂ − x₁ is 0 and the slope is undefined.

Question 3 — A line passes through (2, −3) with slope 3/4. Which point is also on the line?

Here's why: Slope 3/4 means up 3 for every 4 to the right: (2 + 4, −3 + 3) = (6, 0). (5, 1) moves right 3 and up 4, which is slope 4/3.

Question 4 — C(x) = 20x + 3000 and R(x) = 50x. How many items must be sold to break even?

Here's why: Set R(x) = C(x): 50x = 20x + 3000, so 30x = 3000 and x = 100. 60 is 3000 ÷ 50, which ignores the $20 cost of making each item.

Why This Matters

The simplest model

Linear functions are the first models you use for real data, and slope is the idea behind rates of change all the way into calculus.

This shows up everywhere

  • Writing equations of lines (Lesson 2.5).
  • Cost, revenue, and profit models.
  • Rates of change in science and economics.

Mini Knowledge Test

Show what you know — 7 quick questions

Question 1
Find the slope of the line through (−3, 5) and (1, −3).
Here's why: (−3 − 5)/(1 − (−3)) = −8/4 = −2. −1/2 puts the x-change on top.
Question 2
What is the x-intercept of f(x) = 3x − 9?
Here's why: Set f(x) = 0: 3x − 9 = 0, so x = 3. (0, −9) is the y-intercept.
Question 3
Which equation is not a function?
Here's why: x = 4 is a vertical line: the input 4 has infinitely many outputs. y = 4 is horizontal and is a function.
Question 4
What is the slope of y = −7?
Here's why: y = −7 is horizontal. Every point has the same y, so the rise is 0 and the slope is 0.
Question 5
A town had 1,200 residents in 2010 and 2,000 in 2020. What is the average rate of change?
Here's why: (2,000 − 1,200)/(2020 − 2010) = 800/10 = 80 per year. 800 is the total change over the whole decade.
Question 6
A product has cost C(x) = 12x + 900 and revenue R(x) = 30x. What is the break-even point?
Here's why: P(x) = 30x − (12x + 900) = 18x − 900. Break-even when 18x = 900, so x = 50. 30 is 900 ÷ 30 (ignores the cost per item), 75 is 900 ÷ 12, and 18 is the profit per item, not the number of items.
Question 7
Write y = −(2/3)x + 4 in standard form Ax + By = C with integers and A > 0.
Here's why: Multiply every term by 3: 3y = −2x + 12. Add 2x to both sides: 2x + 3y = 12. 2x + 3y = 4 forgets to multiply the 4 by 3; the other two have a sign error on x or y.
