Let's Begin

Six graphs you should know by sight

Almost every graph in this course is one of six basic shapes, moved or stretched. If you can sketch these six from memory, with their domains and ranges, you already know most of Chapter 2. Today we meet them, then glue pieces of graphs together into piecewise functions.

Today you'll learn the basic graphs, evaluate and graph piecewise-defined functions, and work with the greatest integer function.

By the end of today, you will be able to:

  • 1Sketch the identity, squaring, cubing, square root, cube root, and absolute value functions and state each domain, range, and where each increases or decreases
  • 2Evaluate a piecewise-defined function by choosing the right piece
  • 3Graph a piecewise function with correct open and closed endpoints, including the greatest integer function, and find its intervals of continuity

Vocabulary

The basic function gallery

Identity · f(x) = x
D: (−∞, ∞) · R: (−∞, ∞)
Increases on (−∞, ∞)
Squaring · f(x) = x²
D: (−∞, ∞) · R: [0, ∞)
Decreases on (−∞, 0); increases on (0, ∞)
Cubing · f(x) = x³
D: (−∞, ∞) · R: (−∞, ∞)
Increases on (−∞, ∞)
Square Root · f(x) = √x
D: [0, ∞) · R: [0, ∞)
Increases on its whole domain, [0, ∞)
Cube Root · f(x) = ∛x
D: (−∞, ∞) · R: (−∞, ∞)
Increases on (−∞, ∞)
Absolute Value · f(x) = |x|
D: (−∞, ∞) · R: [0, ∞)
Decreases on (−∞, 0); increases on (0, ∞)

💭 Notice: only √x has a restricted domain, x ≥ 0, because you can't take the square root of a negative. The squaring, square root, and absolute value graphs never go below the x-axis, so their range is [0, ∞). Each of the six is continuous on its entire domain. Read increasing and decreasing from left to right, using x-intervals.

Vocabulary

Piecewise and step functions

Piecewise-Defined Function

A function made of different formulas on different intervals of x. Each x uses exactly one piece.

💡Example: f(x) = 2x + 1 if x ≤ 0, and x² if x > 0.
Open vs. Closed Endpoint

≤ or ≥ includes the endpoint: closed dot. < or > leaves it out: open dot.

💡Memory hook: the line under ≤ "fills in" the dot.
Greatest Integer Function

⟦x⟧ is the greatest integer that is less than or equal to x. Its graph is a staircase.

💡Example: ⟦2.7⟧ = 2, ⟦5⟧ = 5, ⟦−1.3⟧ = −2 (round down, even for negatives).
Continuous

A function is continuous on an interval if you can draw its graph there without lifting your pencil.

💡Example: the six basic functions are continuous on their domains; ⟦x⟧ jumps at every integer.

How It Works

Graphing a piecewise function

1
Read each piece
Write down each formula and the x-interval it belongs to.
2
Graph each piece on its interval only
Make a short table of x-values inside the interval, including the endpoint.
3
Mark the endpoints
Closed dot for ≤ or ≥, open dot for < or >. Compute the endpoint's y using that piece's formula, even when the dot is open.
4
Check
Every x should land on exactly one piece. Two closed dots stacked at the same x means a mistake.

Real-World Context

Parking fees are step functions

A garage charges $3 for every hour or part of an hour. Stay 1 hour 10 minutes and you pay for 2 hours. The price jumps at each new hour, which is exactly what a step function does.

Example: Shipping rates, tax brackets, and cell plans with data tiers are piecewise functions: one rule up to a cutoff, a different rule after it.

Worked Example · Evaluating

Choose the right piece first

Goal: f(x) = 2x + 1 if x ≤ 0, and x² if x > 0. Find f(−3), f(0), and f(2).

1
f(−3)
−3 ≤ 0, so use 2x + 1: 2(−3) + 1 = −5
2
f(0)
0 ≤ 0, so use 2x + 1: 2(0) + 1 = 1
3
f(2)
2 > 0, so use x²: 2² = 4

💭 Notice: the x-value picks the piece. Never plug into both and choose the answer you like.

Worked Example · Graphing

Graph the piecewise function

Goal: Graph f(x) = −x + 1 if x ≤ 2, and 2x − 6 if x > 2.

1
Left piece, x ≤ 2
Points (0, 1), (−2, 3), and the endpoint (2, −1). ≤ means a closed dot.
2
Right piece, x > 2
At x = 2: 2(2) − 6 = −2, an open dot at (2, −2). Then (3, 0) and (4, 2).
3
Domain and range
Domain (−∞, ∞). The graph covers every y-value from −2 upward on the right and from −1 upward on the left, so the range is (−2, ∞).
Closed dot at (2, −1), open dot at (2, −2)

Worked Example · Three Pieces

A piecewise function with a constant piece

Goal: Graph f(x) = x + 4 if x < −2, 1 if −2 ≤ x ≤ 1, and 2x − 4 if x > 1. Then find where f is continuous.

1
Left piece, x < −2
y = x + 4 through (−3, 1) and (−4, 0). At x = −2: −2 + 4 = 2, an open dot at (−2, 2).
2
Middle piece, −2 ≤ x ≤ 1
The constant 1 is a horizontal segment at height 1, with closed dots at (−2, 1) and (1, 1).
3
Right piece, x > 1
At x = 1: 2(1) − 4 = −2, an open dot at (1, −2). Then (2, 0) and (3, 2).
4
Intervals of continuity
The pencil must lift at x = −2 and at x = 1. So f is continuous on (−∞, −2), (−2, 1), and (1, ∞), with jumps (discontinuities) at x = −2 and x = 1.
Open (−2, 2), closed (−2, 1) and (1, 1), open (1, −2)

💭 Notice: to test a break point, evaluate both neighboring pieces there. Equal heights join with no break; different heights mean a jump.

Worked Example · Step Function

The greatest integer function

1
Evaluate
⟦3.9⟧ = 3 · ⟦0.5⟧ = 0 · ⟦−0.5⟧ = −1 · ⟦−2⟧ = −2
2
Graph
On [0, 1) the value is 0, on [1, 2) it is 1, and so on. Each step has a closed dot on the left and an open dot on the right.
y = ⟦x⟧: closed on the left of each step, open on the right

Your Turn — Guided Practice

Now you try, with me right here

Work each one, then tap your answer.

Question 1: f(x) = x² if x < −1, and 3x if x ≥ −1. Find f(−1).

Here's why: −1 ≥ −1, so x = −1 belongs to the second piece: 3(−1) = −3. Using x² would give 1, but −1 is not less than −1.

Question 2: What is the domain of f(x) = √x?

Here's why: You can only take the square root of 0 or a positive number, so x ≥ 0. The graph starts at the origin and goes right.

Question 3: g(x) = −x if x ≤ 0, 3 if 0 < x < 2, and x − 1 if x ≥ 2. Find g(2).

Here's why: x = 2 fails 0 < x < 2 (2 is not less than 2) but satisfies x ≥ 2, so use x − 1: 2 − 1 = 1. Using the constant 3 picks the wrong piece.

Question 4: Which graph matches f(x) = x + 2 if x < 1, and −1 if x ≥ 1?

Graph A
Graph B

Here's why: At x = 1 the first piece gives 1 + 2 = 3, but 1 is not less than 1, so (1, 3) is an open dot. The constant piece includes x = 1 (≥), so (1, −1) is a closed dot. Graph B has the dots reversed.

Mini Knowledge Test

Show what you know: 7 quick questions

Question 1
What is the range of f(x) = |x|?
Here's why: Absolute value is never negative, and it equals 0 at x = 0, so the range is [0, ∞) with a bracket at 0.
Question 2
What is the domain of f(x) = ∛x?
Here's why: You can take the cube root of any real number, including negatives: ∛(−8) = −2. Only the square root needs x ≥ 0.
Question 3
f(x) = 4 − x if x < 2, and x² if x ≥ 2. Find f(2).
Here's why: 2 ≥ 2, so use x²: 2² = 4. A function gives one output, so "both" is never right.
Question 4
In a piecewise function, one piece is x + 1 for x < 3. What goes at its endpoint?
Here's why: The y-value comes from the piece: 3 + 1 = 4. The symbol is <, so 3 is not included and the dot is open.
Question 5
Evaluate ⟦−2.4⟧.
Here's why: The greatest integer less than or equal to −2.4 is −3. On a number line, −3 is to the left of −2.4; −2 is to the right, so it is too big.
Question 6
Which graph matches f(x) = 2 if x ≤ −1, and x − 1 if x > −1?
Graph A
Graph B
Graph C
Graph D
Here's why: The constant piece y = 2 is drawn for x ≤ −1 (to the left), ending in a closed dot at (−1, 2). The line y = x − 1 is drawn for x > −1 (to the right), starting at −1 − 1 = −2 with an open dot at (−1, −2). Graph A puts the pieces on the wrong sides, Graph C reverses the dots, and Graph D graphs x + 1 instead of x − 1.
Question 7
f(x) = x + 2 if x < 0, 2 if 0 ≤ x ≤ 3, and x − 2 if x > 3. On which open intervals is f continuous?
Here's why: Check each break point. At x = 0: the left piece approaches 0 + 2 = 2 and the middle piece is 2, so the graph joins with no break. At x = 3: the middle piece is 2 but the right piece starts at 3 − 2 = 1, a jump. So f is continuous on (−∞, 3) and (3, ∞). A boundary between pieces is not automatically a break.
