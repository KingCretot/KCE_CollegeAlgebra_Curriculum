Let's Begin

Every graph is a basic graph that moved

y = (x − 7)² + 1 looks new, but it is just y = x² picked up and moved 7 right and 1 up. Today you learn to read those moves straight off the equation, so you can sketch a graph without making a table.

Today you'll shift, reflect, and stretch the basic graphs from Lesson 2.6, and test a function for symmetry.

By the end of today, you will be able to:

  • 1Shift a graph up, down, left, or right from its equation
  • 2Reflect a graph across the x-axis or y-axis, stretch or shrink it vertically or horizontally, and describe the transformation in words
  • 3Test an equation for symmetry about the x-axis, the y-axis, and the origin, and decide whether a function is even, odd, or neither

Vocabulary

The moves

Vertical Shift

y = f(x) + k moves the graph up k; y = f(x) − k moves it down k.

💡Memory hook: outside the function, the sign means what it says.
Horizontal Shift

y = f(x − h) moves the graph right h; y = f(x + h) moves it left h.

💡Memory hook: inside the function, the sign does the opposite. (x − 7) means right 7.
Reflection

y = −f(x) flips the graph across the x-axis (upside down). y = f(−x) flips it across the y-axis (left to right).

💡Memory hook: negative outside → flips up/down. Negative inside → flips left/right.
Stretch and Shrink

y = a·f(x) with |a| > 1 stretches the graph vertically (narrower); with 0 < |a| < 1 it shrinks (wider).

💡Example: y = 3x² is narrower than y = x²; y = ½x² is wider.
Horizontal Stretch and Shrink

y = f(cx) with |c| > 1 shrinks the graph horizontally (toward the y-axis); with 0 < |c| < 1 it stretches it horizontally. Each x-coordinate is divided by c.

💡Memory hook: inside the function, numbers act backward: f(2x) squeezes the graph to half its width.
Symmetry Tests for Equations

x-axis: replacing y with −y gives an equivalent equation. y-axis: replacing x with −x does. Origin: replacing both does.

💡Example: x = y² − 3 is symmetric about the x-axis, since (−y)² = y².
Even and Odd Functions

Even: f(−x) = f(x), symmetric about the y-axis. Odd: f(−x) = −f(x), symmetric about the origin. Otherwise neither.

💡Shortcut for polynomials: all even powers (a constant counts as even) → even. All odd powers, no constant → odd. A mix → neither.

How It Works

Sketching y = a·f(x − h) + k

1
Name the parent
Which basic graph is it? x², √x, |x|, x³, …
2
Horizontal shift
Look inside: x − h moves right h, x + h moves left h.
3
Reflect or stretch
A negative in front flips it across the x-axis. A number in front stretches or shrinks it.
4
Vertical shift
Look at the end: + k up, − k down.
5
Plot the key point
Move the parent's key point (vertex of x² or |x|, starting point of √x) to (h, k), then draw the shape.

Real-World Context

Same shape, new location

Think of a cookie cutter. The shape never changes; you just choose where to press it. Transformations work the same way: the equation tells you where to place the basic shape and whether to flip it.

Example: A designer drawing an arch uses one parabola and shifts it into place instead of computing every point again.

2
Inside: x − 7

Outside: + 1

Key point
Vertex moves to (7, 1). Opens up, same width as x².

Worked Example · Other Parents

Square root and absolute value

1
y = √(x + 3)
Inside + 3 → left 3. The starting point (0, 0) moves to (−3, 0). Domain [−3, ∞).
2
f(x) = |x| − 5
Outside − 5 → down 5. The vertex moves to (0, −5). Range [−5, ∞).
3
Combine them
y = √(x + 7) + 4 starts at (−7, 4); y = |x − 7| − 4 has its vertex at (7, −4).
y = √(x + 3): starts at (−3, 0)
f(x) = |x| − 5: vertex (0, −5)

Negative in front
Reflect across the x-axis, so it opens down
3
Key point
Vertex (−6, 0)

Worked Example · Stretch and Reflect in Words

Describing the transformation

Goal: Describe how each graph relates to y = x², in words.

1
y = 2(x + 1)² − 3
Inside x + 1: a translation 1 unit to the left. The 2 in front: a vertical stretch by a factor of 2 (narrower). Outside − 3: a translation 3 units down.
2
Check with points
Vertex (−1, −3). One unit either side, the height rises 2 · 1² = 2 (not 1), giving (0, −1) and (−2, −1).
3
y = −x² + 3
The negative in front: a reflection across the x-axis (opens down). Outside + 3: a translation 3 units up. Vertex (0, 3).
4
Shrink
A factor between 0 and 1 is a vertical shrink: y = ½x² is wider than y = x².
y = 2(x + 1)² − 3: vertex (−1, −3)
y = −x² + 3: vertex (0, 3), opens down

💭 Notice: the review-sheet wording names each move: "a translation 6 units to the left and a reflection across the x-axis" describes y = −(x + 6)².

Worked Example · Horizontal Stretch and Shrink

Changes inside: y = f(cx)

Goal: Compare y = √(4x) and y = √(¼x) with y = √x.

1
Rule
For y = f(cx), every point (a, b) on y = f(x) moves to (a/c, b). Heights stay the same; x-coordinates are divided by c.
2
y = √(4x), c = 4
(4, 2) moves to (1, 2) and (16, 4) moves to (4, 4). The graph is shrunk horizontally by a factor of ¼, so it rises faster.
3
y = √(¼x), c = ¼
(1, 1) moves to (4, 1). The graph is stretched horizontally by a factor of 4, so it rises more slowly.
4
Domain
Both still need a nonnegative inside, so both have domain [0, ∞).
y = √(4x): shrunk horizontally
y = √(¼x): stretched horizontally

💭 Notice: √(4x) = 2√x, so for this parent a horizontal shrink and a vertical stretch give the same graph. For most graphs they differ, so use the point rule.

Worked Example · Reflection Across the y-Axis

y = f(−x)

Goal: Graph y = √(−x) by reflecting y = √x across the y-axis.

1
Rule
For y = f(−x), every point (a, b) moves to (−a, b): same height, opposite side of the y-axis.
2
Move key points
(1, 1) → (−1, 1) and (4, 2) → (−4, 2). The starting point (0, 0) stays put.
3
Domain
The inside −x must be ≥ 0, so x ≤ 0. Domain (−∞, 0]; range [0, ∞).
4
Compare
y = −√x is different: the negative is outside, so it flips across the x-axis and points down.
y = √(−x): mirror image of y = √x across the y-axis

💭 Notice: for an even function, f(−x) = f(x), so reflecting across the y-axis changes nothing. That is exactly what y-axis symmetry means.

Worked Example · Symmetry

Even, odd, or neither?

Method: Find f(−x) and compare it with f(x) and with −f(x).

1
f(x) = x⁴ − 2x² − 3
f(−x) = (−x)⁴ − 2(−x)² − 3 = x⁴ − 2x² − 3 = f(x). Even.
2
f(x) = −3x⁵ − 8x³
f(−x) = −3(−x)⁵ − 8(−x)³ = 3x⁵ + 8x³ = −f(x). Odd.
3
f(x) = −3x³ + 6x² + 2
f(−x) = 3x³ + 6x² + 2. That is neither f(x) nor −f(x). Neither.
Even example: y = x² − 2 is symmetric about the y-axis
Odd example: y = x³ − 2x is symmetric about the origin

Worked Example · Symmetry of Equations

x-axis, y-axis, or origin?

Goal: Test x = y² − 3 for symmetry about the x-axis, the y-axis, and the origin.

1
x-axis: replace y with −y
x = (−y)² − 3 = y² − 3. Same equation, so it is symmetric about the x-axis.
2
y-axis: replace x with −x
−x = y² − 3, which is x = −y² + 3. Different equation: not symmetric about the y-axis.
3
Origin: replace both
−x = (−y)² − 3, again x = −y² + 3: not symmetric about the origin.
4
Quick comparisons
y = x² + 4: y-axis only. x² + y² = 16: all three. y = x³: origin only.
x = y² − 3: symmetric about the x-axis

💭 Notice: a graph symmetric about the x-axis (other than y = 0) fails the vertical line test, so it is not a function. So x-axis symmetry is tested on equations such as x = y² − 3, while even and odd describe functions.

Your Turn — Guided Practice

Now you try, with me right here

Work each one, then tap your answer.

Question 1 — Where is the vertex of y = |x − 7| − 4?

Here's why: Inside, x − 7 moves the graph right 7. Outside, − 4 moves it down 4. The vertex goes from (0, 0) to (7, −4).

Question 2 — Is f(x) = −5x³ + 8x² − 5 even, odd, or neither?

Here's why: The powers are mixed: x³ is odd, while x² and the constant are even. f(−x) = 5x³ + 8x² − 5, which matches neither f(x) nor −f(x).

Question 3 — The point (6, 2) is on the graph of y = f(x). Which point must be on the graph of y = f(2x)?

Here's why: For y = f(cx), divide each x-coordinate by c: 6 ÷ 2 = 3, and the height stays 2. The graph shrinks horizontally. Multiplying by 2 to get (12, 2) moves the wrong way.

Question 4 — Describe how y = ½(x − 3)² relates to y = x².

Here's why: Inside x − 3 moves the graph right 3 (inside signs work opposite). A factor of ½ in front makes each height half as large: a vertical shrink, so the graph is wider.

Your Turn: Guided Practice, Part 2

Symmetry, reflections, and graphs

Work each one, then tap your answer.

Question 5 — Is f(x) = x⁶ − 3x² + 1 even, odd, or neither?

Here's why: f(−x) = (−x)⁶ − 3(−x)² + 1 = x⁶ − 3x² + 1 = f(x). All the powers are even (the constant counts as even), so f is even.

Question 6 — Is f(x) = 5x³ + x even, odd, or neither?

Here's why: f(−x) = 5(−x)³ + (−x) = −5x³ − x = −f(x). All powers are odd and there is no constant, so f is odd.

Question 7 — Which graph is y = √(x + 2) − 1?

Graph A
Graph B

Here's why: Inside + 2 moves the graph left 2; outside − 1 moves it down 1. The starting point (0, 0) moves to (−2, −1), which is Graph B. Graph A moved right instead of left.

Question 8 — Which equation is the graph of y = √x reflected across the y-axis?

Here's why: A reflection across the y-axis replaces x with −x inside: y = √(−x). y = −√x puts the negative outside, which reflects across the x-axis instead.

Question 9 — Which symmetry does y² = x + 5 have?

Here's why: Replace y with −y: (−y)² = x + 5 is the same equation, so it is symmetric about the x-axis. Replacing x with −x gives y² = −x + 5, a different equation, so it is not symmetric about the y-axis.

Why This Matters

Transformations save you work

Instead of building a table for every new function, you start from a shape you already know and move it. This idea returns all through the course.

This shows up everywhere

  • Quadratic functions in vertex form (Chapter 3).
  • Exponential and logarithmic graphs (Chapter 4).
  • Function operations and composition (Lesson 2.8).

Mini Knowledge Test

Show what you know — 8 quick questions

Question 1
How does f(x) = (x − 4)² relate to y = x²?
Here's why: The change is inside the parentheses, so the sign works opposite: x − 4 moves the graph right 4.
Question 2
How does f(x) = (x − 6)² + 7 relate to y = x²?
Here's why: Inside x − 6 → right 6. Outside + 7 → up 7. The vertex is (6, 7).
Question 3
Where does the graph of y = √(x + 7) + 4 start?
Here's why: Inside + 7 → left 7. Outside + 4 → up 4. The starting point (0, 0) moves to (−7, 4).
Question 4
How does f(x) = −(x + 6)² relate to y = x²?
Here's why: x + 6 inside → left 6. The negative is outside the square, so the graph flips across the x-axis and opens down.
Question 5
Is f(x) = −3x³ + 6x² + 2 even, odd, or neither?
Here's why: f(−x) = 3x³ + 6x² + 2. That equals neither f(x) nor −f(x) = 3x³ − 6x² − 2. Mixed odd and even powers give neither.
Question 6
Is f(x) = 2x⁴ + x² even, odd, or neither?
Here's why: f(−x) = 2(−x)⁴ + (−x)² = 2x⁴ + x² = f(x), so f is even (symmetric about the y-axis). Every power is even.
Question 7
Is f(x) = x³ − 4x even, odd, or neither?
Here's why: f(−x) = (−x)³ − 4(−x) = −x³ + 4x = −(x³ − 4x) = −f(x), so f is odd (symmetric about the origin). Every power is odd and there is no constant.
Question 8
Which symmetry does the graph of x = −y² + 4 have?
Here's why: Replacing y with −y gives x = −(−y)² + 4 = −y² + 4, the same equation: x-axis symmetry. Replacing x with −x gives −x = −y² + 4, a different equation, so there is no y-axis symmetry, and replacing both gives the same different equation, so no origin symmetry.
