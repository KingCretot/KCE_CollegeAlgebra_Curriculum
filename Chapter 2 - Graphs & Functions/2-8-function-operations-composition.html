Let's Begin

Functions can be combined

You can add, subtract, multiply, and divide functions just like numbers. You can also feed the output of one function into another, which is called composition. A store discount followed by sales tax is a composition: the price goes through one function, then the next.

Today you'll combine functions, find their domains, compute a difference quotient, and compose functions.

By the end of today, you will be able to:

  • 1Find (f + g), (f − g), (fg), and (f/g) and their domains (including square roots), from formulas, tables, or graphs
  • 2Find and simplify the difference quotient
  • 3Find and evaluate compositions (f ∘ g)(x) and (g ∘ f)(x), find the domain of a composition, and decompose h(x) as f(g(x))

Vocabulary

The words for this lesson

Operations on Functions

(f + g)(x) = f(x) + g(x), (f − g)(x) = f(x) − g(x), (fg)(x) = f(x) · g(x), (f/g)(x) = f(x)/g(x).

💡Domain: x must be in both domains; for f/g, also g(x) ≠ 0.
Composition

(f ∘ g)(x) = f(g(x)). Do g first, then put its output into f.

💡Memory hook: work from the inside out, like nested parentheses.
Difference Quotient

[f(x + h) − f(x)]/h, with h ≠ 0. It is the slope between two points on the graph.

💡Example: for f(x) = x² − 3, it simplifies to 2x + h.
Order Matters

Usually f(g(x)) ≠ g(f(x)).

💡Example: with f(x) = x² − 3 and g(x) = 2x + 1, f(g(x)) = 4x² + 4x − 2 but g(f(x)) = 2x² − 5.

How It Works

Composing and combining

1
Evaluate a combination at a number
Find f(a) and g(a) separately, then add, subtract, multiply, or divide.
2
Find a combination as a formula
Combine the expressions and simplify. For f/g, list the x-values that make g(x) = 0 and exclude them.
3
Compose
Replace every x in the outer function with the whole inner function, in parentheses.
4
Evaluate a composition at a number
Inside out: (f ∘ g)(1) = f(g(1)).

💭 Notice: (f ∘ g)(x) means compose, not multiply. (fg)(x) is the product.

Real-World Context

Discount, then tax

A store takes 20% off, then adds 7% sales tax. If d(x) = 0.8x is the discounted price and t(x) = 1.07x adds tax, the final price is t(d(x)) = 1.07(0.8x) = 0.856x.

Example: A $50 item: d(50) = 40, then t(40) = $42.80.

Worked Example · Operations

f(x) = x² − 3, g(x) = 2x + 1

1
(f + g)(2)
f(2) = 1, g(2) = 5, so (f + g)(2) = 6
2
(fg)(−1)
f(−1) = −2, g(−1) = −1, so (fg)(−1) = 2
3
(f/g)(x) and its domain
(x² − 3)/(2x + 1). 2x + 1 = 0 when x = −1/2, so the domain is (−∞, −1/2) ∪ (−1/2, ∞).

Worked Example · Domains with Radicals

When one function has a square root

Goal: f(x) = 8x − 9 and g(x) = √(2x − 1). Find the domains of f + g, f − g, fg, f/g, and g/f.

1
Domain of each function
f is a line: (−∞, ∞). g needs 2x − 1 ≥ 0, so x ≥ ½: [½, ∞).
2
f + g, f − g, fg
x must be in both domains: the overlap is [½, ∞). For example, (f + g)(5) = 31 + √9 = 34.
3
f/g
Also need g(x) ≠ 0. g(½) = √0 = 0, so ½ is removed: (½, ∞).
4
g/f
Need f(x) ≠ 0: 8x − 9 = 0 at x = 9/8. Domain [½, 9/8) ∪ (9/8, ∞).

💭 Notice: a square root in the denominator needs a strictly positive inside, so the bracket at ½ becomes a parenthesis.

Worked Example · Difference Quotient

f(x) = x² − 3

1
f(x + h)
(x + h)² − 3 = x² + 2xh + h² − 3
2
Subtract f(x)
x² + 2xh + h² − 3 − (x² − 3) = 2xh + h²
3
Divide by h
(2xh + h²)/h = 2x + h

💭 Common slip: (x + h)² is x² + 2xh + h², not x² + h².

Worked Example · Composition

f(x) = x² − 3, g(x) = 2x + 1

1
(f ∘ g)(x)
f(2x + 1) = (2x + 1)² − 3 = 4x² + 4x + 1 − 3 = 4x² + 4x − 2
2
(g ∘ f)(x)
g(x² − 3) = 2(x² − 3) + 1 = 2x² − 5
3
(f ∘ g)(1)
g(1) = 3, then f(3) = 9 − 3 = 6. Check with the formula: 4 + 4 − 2 = 6 ✓

Worked Example · Domain of a Composition

What can go into f ∘ g?

Rule: the domain of f ∘ g is every x that is in the domain of g and whose output g(x) is in the domain of f. Find it before you simplify.

1
f(x) = √x, g(x) = x − 3
(f ∘ g)(x) = f(x − 3) = √(x − 3).
2
Domain
g accepts every x. f needs its input ≥ 0: x − 3 ≥ 0, so x ≥ 3. Domain [3, ∞).
3
f(x) = 1/(x − 2), g(x) = 1/x
(f ∘ g)(x) = 1/(1/x − 2), which simplifies to x/(1 − 2x).
4
Domain
g needs x ≠ 0. f needs its input ≠ 2: 1/x ≠ 2, so x ≠ ½. Domain (−∞, 0) ∪ (0, ½) ∪ (½, ∞).

💭 Notice: the simplified form x/(1 − 2x) hides the restriction x ≠ 0. Always use the original pieces to find the domain.

Worked Example · Decomposition

Splitting h(x) into f(g(x))

Goal: Write h(x) = (6x − 2)² as f(g(x)).

1
Find the inside
Ask: what is calculated first? 6x − 2. Let g(x) = 6x − 2.
2
Find the outside
Then the result is squared. Let f(x) = x².
3
Check
f(g(x)) = f(6x − 2) = (6x − 2)² = h(x) ✓
4
Another one
h(x) = √(x² − 1): g(x) = x² − 1 (inside), f(x) = √x (outside).

💭 Notice: decompositions are not unique. Any pair that checks out is correct, but the natural choice is "inside = g, outside = f".

Why This Matters

Building new functions from old ones

Composition is how real processes chain together, and it is the key to inverse functions at the start of Chapter 4.

This shows up everywhere

  • Inverse functions (Chapter 4).
  • Unit conversions and multi-step pricing.
  • The difference quotient is the first step toward the derivative in calculus.

Mini Knowledge Test

Show what you know — 8 quick questions

Question 1
If f(x) = 3x − 1 and g(x) = x², find (f + g)(2).
Here's why: f(2) = 5 and g(2) = 4, so 5 + 4 = 9. 20 is the product (fg)(2).
Question 2
With f(x) = 3x − 1 and g(x) = x², find (f ∘ g)(x).
Here's why: Put g inside f: f(x²) = 3x² − 1. (3x − 1)² is (g ∘ f)(x), the other order; 3x² + 1 adds the 1 instead of subtracting it; 3x³ − x² multiplies f and g instead of composing them.
Question 3
With f(x) = 3x − 1 and g(x) = x², find (g ∘ f)(x).
Here's why: g(3x − 1) = (3x − 1)² = 9x² − 6x + 1. Squaring term by term to get 9x² + 1 skips the middle term.
Question 4
If f(x) = x + 5 and g(x) = x − 4, what is the domain of (f/g)(x)?
Here's why: The denominator g(x) = x − 4 can't be 0, so x ≠ 4. The numerator being 0 at −5 is allowed.
Question 5
Find the difference quotient of f(x) = 4x − 7.
Here's why: [4(x + h) − 7 − (4x − 7)]/h = 4h/h = 4. For a line, the difference quotient is always the slope.
Question 6
f(x) = 2/(x − 1) and g(x) = 1/x. What is the domain of (f ∘ g)(x)?
Here's why: g needs x ≠ 0. f needs its input ≠ 1: 1/x ≠ 1, so x ≠ 1. Both are excluded. (f ∘ g)(x) simplifies to 2x/(1 − x), which hides x ≠ 0, so (−∞, 1) ∪ (1, ∞) is too big; (−∞, 0) ∪ (0, ∞) checks only g.
Question 7
Find f and g so that h(x) = (5x + 2)³ = f(g(x)).
Here's why: The inside, 5x + 2, is g; cubing it last is f. Check: f(g(x)) = (5x + 2)³ ✓. The first pair gives 5x³ + 2, the second 125x³, and the third 125x³ + 2.
Question 8
f(x) = 4x − 1 and g(x) = √(x − 3). What is the domain of (f/g)(x)?
Here's why: g needs x − 3 ≥ 0, so x ≥ 3, and as a denominator g(x) ≠ 0, so x ≠ 3. Domain (3, ∞). [3, ∞) forgets that g(3) = 0; (¼, ∞) uses the zero of the numerator, which is allowed.
