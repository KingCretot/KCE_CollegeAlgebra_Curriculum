Key Ideas · Lessons 2.1–2.2

Coordinates and circles

Lesson 2.1

Distance, midpoint, intercepts

d = √[(x₂ − x₁)² + (y₂ − y₁)²]. Midpoint: average the x's and average the y's. x-intercept: set y = 0. y-intercept: set x = 0.

Example: (1, −2) to (7, 6): √(36 + 64) = 10
Lesson 2.2

Circles

Center-radius form (x − h)² + (y − k)² = r²; the signs inside flip. From general form, complete the square in x and in y. A negative right side means no graph.

Example: x² + y² − 6x + 10y + 25 = 0 → (x − 3)² + (y + 5)² = 9

Key Ideas · Lessons 2.3–2.5

Functions and lines

Lesson 2.3

Functions

Each input has exactly one output; use the vertical line test on graphs. Domain = x-values, range = y-values. Evaluate with parentheses; f(−x) replaces every x with (−x).

Example: f(x) = 5x² + 5x + 3 → f(−2) = 13
Lesson 2.4

Linear functions and slope

m = (y₂ − y₁)/(x₂ − x₁). Horizontal y = b has slope 0; vertical x = a has undefined slope and is not a function. Slope is a rate of change.

Example: (−2, 6) and (4, −3): m = −3/2
Lesson 2.5

Equations of lines

Point-slope y − y₁ = m(x − x₁), slope-intercept y = mx + b, standard Ax + By = C. Parallel: same slope. Perpendicular: negative reciprocal.

Example: ⊥ to y = 2x − 5 through (4, 1): y = −½x + 3

Key Ideas · Lessons 2.6–2.8

Graphs and combining functions

Lesson 2.6

Basic graphs and piecewise functions

Know x, x², x³, √x, ∛x, |x| with domains and ranges. Piecewise: the x-value chooses the piece; ≤/≥ closed dot, </> open dot. ⟦x⟧ rounds down.

Example: ⟦−2.4⟧ = −3
Lesson 2.7

Transformations and symmetry

Inside changes are horizontal and opposite: f(x − h) moves right h. Outside changes are vertical: + k up. −f(x) flips over the x-axis. Even: f(−x) = f(x). Odd: f(−x) = −f(x).

Example: (x − 6)² + 7: right 6, up 7
Lesson 2.8

Operations and composition

(f + g)(x) = f(x) + g(x), etc.; for f/g, exclude g(x) = 0. (f ∘ g)(x) = f(g(x)), inside out. Difference quotient [f(x + h) − f(x)]/h.

Example: f(x) = x² − 3, g(x) = 2x + 1 → f(g(x)) = 4x² + 4x − 2

Watch Out

The mistakes that cost the most points

The mistakeThe fix
Adding the coordinate differences without squaringDistance needs squares and a square root: √(Δx² + Δy²).
Reading (x + 3)² as center x = 3The signs inside flip: (x + 3)² means h = −3.
Using r² as the radiusIf the right side is 20, the radius is √20 = 2√5.
Thinking repeated y-values break a functionOnly a repeated x with different y-values breaks it.
Writing −2² for (−2)² when evaluatingAlways substitute in parentheses: 5(−2)² = 20.
Calling a vertical line's slope 0Vertical: undefined. Horizontal: 0.
Using the same slope for perpendicular linesPerpendicular slopes are negative reciprocals: 2 → −1/2.
Moving f(x − 4) leftInside changes go the opposite way: right 4.
Doing f(g(x)) in the wrong orderInside first: find g(x), then put it into f.

Practice Test

10 questions, every lesson mixed together

Just like a unit test, these jump between lessons. You get two tries on each question, and every question explains itself after you answer.

Question 1
Find the midpoint of (−6, 3) and (4, −7).
Here's why: ((−6 + 4)/2, (3 + (−7))/2) = (−2/2, −4/2) = (−1, −2).
Question 2
Find the center and radius of x² + y² + 4x − 8y − 5 = 0.
Here's why: (x² + 4x + 4) + (y² − 8y + 16) = 5 + 4 + 16 = 25, so (x + 2)² + (y − 4)² = 25. Center (−2, 4), radius 5.
Question 3
Which relation is a function?
Here's why: Only {(1, 3), (2, 3), (3, 3)} has no repeated x-value. Repeating the output 3 is allowed.
Question 4
If f(x) = x² − 4x + 1, find f(−3).
Here's why: (−3)² − 4(−3) + 1 = 9 + 12 + 1 = 22. −20 comes from treating (−3)² as −9 and −4(−3) as −12.
Question 5
Find the slope of the line through (−4, 1) and (2, −8).
Here's why: (−8 − 1)/(2 − (−4)) = −9/6 = −3/2.
Question 6
Write the line through (−2, 3) perpendicular to y = 2x + 7.
Here's why: Perpendicular slope −1/2. y − 3 = −½(x + 2) = −½x − 1, so y = −½x + 2.
Question 7
What is the range of f(x) = |x| − 5?
Here's why: |x| has range [0, ∞); shifting down 5 makes it [−5, ∞).
Question 8
f(x) = x + 4 if x < 1, and 2x² if x ≥ 1. Find f(1).
Here's why: 1 ≥ 1, so use 2x²: 2(1)² = 2. Using x + 4 gives 5, but that piece is only for x < 1.
Question 9
How does f(x) = −√(x − 2) relate to y = √x?
Here's why: x − 2 inside → right 2. The negative is outside the root, so the graph flips across the x-axis.
Question 10
If f(x) = 2x + 3 and g(x) = x² − 1, find (f ∘ g)(2).
Here's why: Inside first: g(2) = 3. Then f(3) = 2(3) + 3 = 9. 48 is g(f(2)) = 7² − 1.
