Let's Begin

Every parabola has a turning point

Throw a ball and it rises, slows, turns, and falls. That path is a parabola, the graph of a quadratic function. The turning point, called the vertex, answers the questions people actually ask: how high, how far, how much profit at most.

Today you'll graph quadratic functions, find the vertex two different ways, and use the vertex to solve maximum and minimum problems.

By the end of today, you will be able to:

  • 1Graph f(x) = a(x − h)² + k and identify its vertex, axis, and direction
  • 2Find the vertex by completing the square or with x = −b/(2a)
  • 3Solve maximum and minimum problems with a quadratic model

Vocabulary

The words for this lesson

Quadratic Function

f(x) = ax² + bx + c with a ≠ 0. Its graph is a parabola.

💡Direction: a > 0 opens up (a minimum); a < 0 opens down (a maximum).
Vertex

The turning point of the parabola: its lowest point if it opens up, its highest if it opens down.

💡Memory hook: the vertex is where the answer to “how high” or “how low” lives.
Vertex Form

f(x) = a(x − h)² + k, with vertex (h, k) and axis of symmetry x = h.

💡Watch the sign: (x + 3)² means h = −3.
Vertex Formula

For f(x) = ax² + bx + c, the vertex is at x = −b/(2a). Find y by plugging that x into f.

💡Example: f(x) = x² − 6x + 5 has vertex x = 6/2 = 3, y = f(3) = −4.
a > 0: opens up, vertex is a minimum
a < 0: opens down, vertex is a maximum

How It Works

Reading and finding the vertex

1
Vertex form
In f(x) = a(x − h)² + k, read the vertex (h, k) straight off. It is y = x² shifted right h and up k.
2
Check a
If a > 0 the parabola opens up; if a < 0 it opens down. If |a| > 1 it is narrower than y = x²; if |a| < 1 it is wider.
3
Standard form
For f(x) = ax² + bx + c, either complete the square to get vertex form, or use x = −b/(2a) and then find f of that x.
4
Intercepts
y-intercept: f(0) = c. x-intercepts: solve ax² + bx + c = 0 (Lesson 1.4). There may be two, one, or none.

💭 Notice: The axis of symmetry x = h cuts the parabola into mirror halves, so x-intercepts are always the same distance from it.

Real-World Context

The highest point of a throw

A ball is thrown upward from a 6-foot platform at 64 feet per second. Its height after t seconds is s(t) = −16t² + 64t + 6. Since a = −16 < 0, the vertex is the highest point.

s(t) = −16t² + 64t + 6

Example: t = −b/(2a) = −64/(2 · −16) = 2 seconds, and s(2) = −64 + 128 + 6 = 70. The ball tops out at 70 feet after 2 seconds.

Worked Example · Vertex Form

Graph f(x) = −2(x + 1)² + 3

1
Vertex
(x + 1) = (x − (−1)), so h = −1 and k = 3. Vertex (−1, 3).
2
Direction and width
a = −2: opens down and is narrower than y = x².
3
Axis, domain, range
Axis x = −1. Domain (−∞, ∞). Range (−∞, 3], because 3 is the highest y-value.
f(x) = −2(x + 1)² + 3

💭 Notice: The range depends on the direction: opening down, the range is (−∞, k]; opening up, it is [k, ∞).

Worked Example · Completing the Square

Write f(x) = x² − 6x + 5 in vertex form

1
Group the x-terms
f(x) = (x² − 6x) + 5
2
Add and subtract (b/2)²
Half of −6 is −3, and (−3)² = 9: f(x) = (x² − 6x + 9) − 9 + 5
3
Factor
f(x) = (x − 3)² − 4. Vertex (3, −4), opens up, minimum value −4.

💭 Common slip: When a ≠ 1, factor a out of the x-terms first: 2x² + 8x + 1 = 2(x² + 4x) + 1 = 2(x + 2)² − 8 + 1 = 2(x + 2)² − 7. The 4 you added inside is really 2 · 4 = 8.

Worked Example · Vertex Formula

Find the vertex of f(x) = 3x² + 12x + 7

1
x-coordinate
x = −b/(2a) = −12/(2 · 3) = −2
2
y-coordinate
f(−2) = 3(4) + 12(−2) + 7 = 12 − 24 + 7 = −5
3
Conclusion
Vertex (−2, −5). a = 3 > 0, so −5 is the minimum value and the range is [−5, ∞).

💭 Common slip: −b/(2a) gives only the x-coordinate. You still have to plug it in to get the y-coordinate, which is the actual maximum or minimum value.

Your Turn — Guided Practice

Now you try, with me right here

Work each one, then tap your answer.

Question 1 — What is the vertex of f(x) = 4(x − 5)² − 2?

Here's why: In a(x − h)² + k, h is the number being subtracted. (x − 5) means h = 5, and k = −2. (−5, −2) flips the sign of h.

Question 2 — A company's profit is P(x) = −x² + 40x − 300 dollars when it sells x items. How many items give the maximum profit?

Here's why: x = −b/(2a) = −40/(2 · −1) = 20. Selling 20 items gives the most profit: P(20) = −400 + 800 − 300 = $100. 40 forgets to divide by 2a.

Why This Matters

The vertex answers “how much at most?”

Any time a quantity rises and then falls (or falls and then rises), a quadratic model and its vertex give the best possible value. This lesson also starts Chapter 3's big question: what do graphs of higher-degree polynomials look like?

This shows up everywhere

  • Projectile height, the maximum area of a fenced region, and maximum revenue.
  • Lesson 3.4 graphs polynomials of higher degree using the same ideas of intercepts and turning points.
  • Vertex form is a transformation of y = x², the same moves from Lesson 2.7.

Mini Knowledge Test

Show what you know — 5 quick questions

Question 1
What is the vertex of f(x) = (x + 4)² − 7?
Here's why: (x + 4) = (x − (−4)), so h = −4; k = −7. The vertex is (−4, −7).
Question 2
Which statement about f(x) = −½(x − 2)² + 6 is true?
Here's why: a = −½ < 0, so it opens down and the vertex (2, 6) is the highest point: maximum value 6. |a| < 1 makes it wider, not narrower.
Question 3
Write f(x) = x² + 8x + 10 in vertex form.
Here's why: Half of 8 is 4, and 4² = 16: (x² + 8x + 16) − 16 + 10 = (x + 4)² − 6.
Question 4
Find the vertex of f(x) = 2x² − 8x + 1.
Here's why: x = −(−8)/(2 · 2) = 2. f(2) = 8 − 16 + 1 = −7. The vertex is (2, −7).
Question 5
What is the range of f(x) = −3(x + 1)² + 5?
Here's why: a = −3 < 0, so the parabola opens down from its vertex (−1, 5). The largest y-value is 5, so the range is (−∞, 5].
