Let's Begin

Divide a polynomial with just the numbers

Long division of polynomials works, but it is slow and full of chances to drop a sign. When the divisor is x − k, there is a shortcut that keeps only the coefficients: synthetic division. Your calculator uses the same idea to evaluate polynomials, because it takes fewer steps than plugging in.

Today you'll divide by x − k with synthetic division, use the remainder to evaluate a polynomial, and test whether a number is a zero.

By the end of today, you will be able to:

  • 1Divide a polynomial by x − k using synthetic division
  • 2Use the remainder theorem to find f(k)
  • 3Decide whether a number k, real or nonreal, is a zero of a polynomial

Vocabulary

The words for this lesson

Synthetic Division

A shortcut for dividing a polynomial by x − k using only k and the coefficients: bring down, multiply by k, add, repeat.

💡Memory hook: “multiply, add” over and over. You add, never subtract.
Division Algorithm

f(x) = g(x) · q(x) + r(x), where r(x) = 0 or has lower degree than g(x). When dividing by g(x) = x − k, the remainder r is a constant and the quotient has degree one less than f.

💡Example: x² + 5x + 7 = (x + 2)(x + 3) + 1.
Remainder Theorem

When f(x) is divided by x − k, the remainder is f(k).

💡Watch the sign: dividing by x + 3 means k = −3, so the remainder is f(−3).
Zero of a Polynomial

A number k with f(k) = 0. With synthetic division, k is a zero exactly when the remainder is 0.

💡Example: 2 is a zero of x² − 4 because 2² − 4 = 0.

How It Works

Synthetic division, step by step

1
Set it up
Write k in the box. For x − 4, k = 4; for x + 4, k = −4. Next to it, list the coefficients in order of descending powers. Write 0 for any missing power.
2
Bring down
Bring the first coefficient straight down below the line.
3
Multiply, add, repeat
Multiply the number you just brought down by k, write the product under the next coefficient, and add the column. Repeat until you reach the last column.
4
Read the bottom row
The last number is the remainder. The other numbers are the coefficients of the quotient, which starts one degree lower than f.

(x³ + 4x² − 5x + 8) ÷ (x + 2): k = −2

−214−58
−2−418
12−926

Bottom row 1, 2, −9 and remainder 26: the quotient is x² + 2x − 9, remainder 26.

💭 Notice: Each multiply-and-add step is exactly what long division does, but with the signs pre-flipped. That is why you add instead of subtract.

Real-World Context

How a calculator evaluates a polynomial

A coach models a sprinter's distance (in meters) after t seconds of a training run with d(t) = −t³ + 6t² + 4t. To find d(4), you could cube, square, and multiply. Or you could run synthetic division with k = 4 and read the remainder. Computers use this second way (called Horner's method) because it needs fewer multiplications.

Worked Example · Basic Synthetic Division

Divide (x³ + 4x² − 5x + 8) by (x + 2)

1
Find k and set up
x + 2 = x − (−2), so k = −2. Coefficients: 1, 4, −5, 8.
−214−58
−2−418
12−926
2
Multiply and add
Bring down 1. Then 1 · (−2) = −2, and 4 + (−2) = 2. Then 2 · (−2) = −4, and −5 + (−4) = −9. Then −9 · (−2) = 18, and 8 + 18 = 26.
3
Read the answer
Quotient x² + 2x − 9, remainder 26. Answer: x² + 2x − 9 + 26/(x + 2).

💭 Common slip: Using k = 2 for the divisor x + 2. The number in the box is the value that makes the divisor 0.

Worked Example · Remainder Theorem

Is −3 a zero of f(x) = 2x³ + 5x² − 4x − 3?

1
Divide by x + 3
Testing k = −3 means dividing by x − (−3) = x + 3. Coefficients: 2, 5, −4, −3.
−325−4−3
−633
2−1−10
2
Read the remainder
The remainder is 0, so by the remainder theorem f(−3) = 0. Check: 2(−27) + 5(9) + 12 − 3 = −54 + 45 + 12 − 3 = 0.
3
Conclusion
Yes, −3 is a zero, and the bottom row gives the rest: f(x) = (x + 3)(2x² − x − 1).

💭 Notice: A remainder of 0 does double duty. It says k is a zero, and the bottom row hands you a smaller polynomial to factor. Lesson 3.3 builds on exactly this.

Worked Example · Testing a Nonreal Zero

Is 1 + i a zero of f(x) = x³ − x² + 2?

1
Set it up
Synthetic division works the same way when k is a complex number, k = 1 + i. Coefficients: 1, −1, 0, 2 (0 for the missing x term).
1 + i1−102
1 + i−1 + i−2
1i−1 + i0
2
Multiply and add
Use i² = −1 in every product. Bring down 1. 1(1 + i) = 1 + i, and −1 + (1 + i) = i. Then i(1 + i) = i + i² = −1 + i, and 0 + (−1 + i) = −1 + i. Then (−1 + i)(1 + i) = −1 − i + i + i² = −2, and 2 + (−2) = 0.
3
Conclusion
The remainder is 0, so f(1 + i) = 0 and yes, 1 + i is a zero. The bottom row gives f(x) = (x − (1 + i))(x² + ix + (−1 + i)).

💭 Common slip: Treating i² as +1. Every time a product makes i², replace it with −1 before you add the column.

Your Turn — Guided Practice

Now you try, with me right here

Work each one, then tap your answer.

Question 1: What is the remainder when x³ − 2x² + 4 is divided by x − 3?

Here's why: By the remainder theorem the remainder is f(3) = 27 − 18 + 4 = 13. (Synthetic division with coefficients 1, −2, 0, 4 and k = 3 agrees.) −41 is f(−3): it uses k = −3, but x − 3 means k = 3.

Question 2: What is the quotient when x³ − 7x + 6 is divided by x − 2?

Here's why: Use coefficients 1, 0, −7, 6 with k = 2: the bottom row is 1, 2, −3 with remainder 0, so the quotient is x² + 2x − 3. x − 5 comes from leaving out the 0 for the missing x² term (1, −7, 6), which also gives a false remainder of −4.

Question 3: Use synthetic division with k = 2i. Is 2i a zero of f(x) = x³ − 2x² + 4x − 8?

Here's why: Coefficients 1, −2, 4, −8 with k = 2i. Bring down 1. 1(2i) = 2i, so −2 + 2i. (−2 + 2i)(2i) = −4i + 4i² = −4 − 4i, so 4 + (−4 − 4i) = −4i. (−4i)(2i) = −8i² = 8, so −8 + 8 = 0. The remainder is 0, so 2i is a zero. Answering “No” usually comes from treating i² as +1 somewhere along the row.

Why This Matters

The remainder is a shortcut to f(k)

Synthetic division turns a messy division into a short row of arithmetic, and the remainder theorem turns that row into a function value. Together they are the main tool for hunting down the zeros of a polynomial, which is the rest of this chapter.

This shows up everywhere

  • Lesson 3.3 uses synthetic division to test possible zeros and to factor polynomials of degree 3 and higher.
  • Lesson 3.4 uses those zeros to sketch polynomial graphs.
  • Calculators and computer programs evaluate polynomials with this same multiply-add routine (Horner's method).

Mini Knowledge Test

Show what you know: 6 quick questions

Question 1
Which is the correct setup for (4x³ − x + 9) ÷ (x + 3)?
Here's why: x + 3 = x − (−3), so k = −3. There is no x² term, so a 0 goes in its place: 4, 0, −1, 9. Using 3 flips the sign of k; dropping the 0 shifts every column.
Question 2
Divide: (x³ + 2x² − 5x − 1) ÷ (x − 2)
Here's why: k = 2 with coefficients 1, 2, −5, −1 gives bottom row 1, 4, 3 and remainder 5. The quotient is one degree lower than the dividend, and the remainder goes over the divisor x − 2. x² − 5 comes from using k = −2; x³ + 4x² + 3x + 5 forgets to lower the degree.
Question 3
Use the remainder theorem: if f(x) = x⁴ − 3x³ + 2x − 5, what is f(2)?
Here's why: Coefficients 1, −3, 0, 2, −5 with k = 2 give bottom row 1, −1, −2, −2 and remainder −9, so f(2) = −9. Check: 16 − 24 + 4 − 5 = −9. 31 is f(−2); −5 comes from skipping the 0 for x²; −2 is the last quotient number, not the remainder.
Question 4
Synthetic division of f(x) = x³ − 4x² + x + 6 by x − 3 leaves remainder 0. Which statement is true?
Here's why: Remainder 0 when dividing by x − 3 means f(3) = 0: 27 − 36 + 3 + 6 = 0. So 3 is a zero and x − 3 is a factor. The zero k and the factor x − k always have opposite-looking signs.
Question 5
The bottom row of synthetic division by x + 4 is 2   −1   0   5   |  −3 (the last number is the remainder). What is the result?
Here's why: Four quotient numbers mean a degree-3 quotient: 2x³ − x² + 0x + 5. The remainder −3 goes over the divisor, x + 4. Ignoring the 0 and sliding the 5 into the x-slot gives 5x, and forgetting the degree drop gives 2x⁴ − x³ + 5x − 3.
Question 6
Use synthetic division with k = i to find the remainder when f(x) = x³ + 2x² + x + 3 is divided by x − i. Is i a zero of f?
Here's why: Coefficients 1, 2, 1, 3 with k = i give the bottom row 1, 2 + i, 2i and remainder 1. Check: f(i) = i³ + 2i² + i + 3 = −i − 2 + i + 3 = 1. The remainder is not 0, so i is not a zero. 1 + 2i treats i³ as i instead of −i, and 5 + 2i treats i² as +1.

Debrief

What we learned today

You can divide a polynomial by x − k with synthetic division, including placeholder zeros.
You can use the remainder theorem to find f(k) from the remainder.
You can decide whether k is a zero by checking for a remainder of 0, even when k is a nonreal complex number like 1 + i.
