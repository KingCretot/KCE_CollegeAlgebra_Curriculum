Let's Begin

Some graphs chase a line forever

Bake more loaves and the cost per loaf drops, but it can't drop to zero. It levels off at a floor. Graphs like that come from rational functions, which are quotients of polynomials. The lines they approach but never reach are called asymptotes.

Today you'll graph the basic rational functions, find every kind of asymptote and hole, and read what a rational model says about the long run.

By the end of today, you will be able to:

  • 1Graph y = 1/x and y = 1/x² and their transformations
  • 2Find vertical, horizontal, and oblique asymptotes, and locate holes
  • 3Graph rational functions and interpret them in applications

Vocabulary

The words for this lesson

Rational Function

f(x) = p(x)/q(x), where p and q are polynomials and q(x) ≠ 0. The domain leaves out every x that makes the denominator 0.

💡Example: f(x) = (x + 1)/(x − 3) has domain all real numbers except 3.
Vertical Asymptote

A vertical line x = a that the graph approaches but never touches, with y-values shooting toward ∞ or −∞. It sits where the simplified denominator is 0.

💡Watch out: if a factor (x − a) cancels from top and bottom, x = a is a hole, not an asymptote.
Horizontal Asymptote

A horizontal line y = b that the graph approaches as x → ±∞. Bottom degree bigger: y = 0. Equal degrees: y = ratio of the leading coefficients.

💡Memory hook: it only describes the far left and far right. The graph is allowed to cross it in the middle.
Oblique Asymptote

A slanted line y = mx + b that the graph approaches when the numerator's degree is exactly one more than the denominator's. Divide to find it.

💡Example: (x² + x − 1)/(x − 1) = x + 2 + 1/(x − 1), so the oblique asymptote is y = x + 2.
y = 1/x: asymptotes x = 0 and y = 0
y = 1/x²: both branches stay above the x-axis

How It Works

Graphing a rational function, step by step

1
Factor and cancel
Factor the top and bottom. If a factor (x − a) cancels, there is a hole at x = a. Find its y-value by plugging a into the simplified function.
2
Vertical asymptotes
Set the simplified denominator equal to 0. Each solution is a vertical asymptote x = a.
3
Horizontal or oblique
Compare degrees, top n and bottom m. If n < m: y = 0. If n = m: y = (leading coef. of top)/(leading coef. of bottom). If n = m + 1: divide, and the quotient is the oblique asymptote.
4
Intercepts and plot
y-intercept: f(0). x-intercepts: zeros of the simplified numerator. Plot a point or two in each region between asymptotes, then sketch.
f(x) = (x² + x − 1)/(x − 1)

💭 Notice: A graph can never cross a vertical asymptote, but it can cross a horizontal one. Horizontal and oblique asymptotes only describe what happens far to the left and right.

Real-World Context

The floor under average cost

A bakery pays $600 a day in fixed costs (rent, ovens, insurance) plus $2 in ingredients per loaf. If it bakes x loaves, the average cost per loaf is C̄(x) = (2x + 600)/x. Top and bottom both have degree 1, so the horizontal asymptote is y = 2/1 = 2. That line tells the owner something real: the average can get close to $2, but it can't go below it.

Average cost per loaf (x in hundreds of loaves)

Example: At 150 loaves, C̄(150) = (300 + 600)/150 = $6 per loaf. At 600 loaves, C̄(600) = (1200 + 600)/600 = $3 per loaf. Baking more spreads out the fixed cost, so the average falls toward $2 per loaf without ever reaching it.

Worked Example · Transformations

Graph f(x) = 1/(x + 2) − 3

1
Start from y = 1/x
f(x) = 1/(x + 2) − 3 is y = 1/x shifted left 2 (inside change, opposite direction) and down 3.
2
Move the asymptotes
The asymptotes move with the graph: x = 0 becomes x = −2, and y = 0 becomes y = −3. Two points: f(−1) = −2 and f(−3) = −4.
3
Domain and range
Domain (−∞, −2) ∪ (−2, ∞). Range (−∞, −3) ∪ (−3, ∞), because the graph never reaches y = −3.
f(x) = 1/(x + 2) − 3

💭 Common slip: x + 2 in the denominator means the vertical asymptote is x = −2, not x = 2. Set the denominator equal to 0 and solve.

Worked Example · Asymptotes and Intercepts

Graph f(x) = (2x − 4)/(x + 1)

1
Vertical asymptote
Nothing cancels. x + 1 = 0 gives x = −1.
2
Horizontal asymptote
Top and bottom both have degree 1, so y = 2/1: y = 2.
3
Intercepts
x-intercept: 2x − 4 = 0, so (2, 0). y-intercept: f(0) = −4/1, so (0, −4). Graph: VA x = −1, HA y = 2, through (2, 0) and (0, −4).
f(x) = (2x − 4)/(x + 1)

💭 Common slip: A vertical asymptote comes from the denominator; an x-intercept comes from the numerator. Mixing them up is the most common slip on this kind of problem.

Worked Example · Holes

Graph f(x) = (x − 3)/(x² − x − 6)

1
Factor
x² − x − 6 = (x − 3)(x + 2), so f(x) = (x − 3)/[(x − 3)(x + 2)].
2
Cancel, and mark the hole
(x − 3) cancels, leaving 1/(x + 2) with x ≠ 3. Plug 3 into what is left: 1/(3 + 2) = 1/5. Hole at (3, 1/5).
3
Asymptotes
The leftover denominator gives the vertical asymptote x = −2. The original bottom has the bigger degree (2 vs. 1), so the horizontal asymptote is y = 0.
f(x) = (x − 3)/(x² − x − 6): hole at (3, 1/5)

💭 Common slip: Do not call x = 3 an asymptote just because it makes the original denominator 0. Cancel first: a factor that cancels leaves a hole, drawn as an open circle.

Your Turn — Guided Practice

Now you try, with me right here

Work each one, then tap your answer.

Question 1 — What is the horizontal asymptote of f(x) = (3x² − 5)/(6x² + x)?

Here's why: The degrees are equal (2 and 2), so y = 3/6 = ½. y = 0 is the rule for when the denominator has the higher degree, which is not the case here.

Question 2 — Find the oblique asymptote of f(x) = (x² − 3x + 5)/(x − 1).

Here's why: Synthetic division with k = 1: 1, −3, 5 becomes 1, −2, remainder 3. So f(x) = x − 2 + 3/(x − 1), and the asymptote is y = x − 2. y = x − 4 comes from dividing with k = −1; for x − 1, k is positive 1.

Why This Matters

Asymptotes describe limits in real life

Rational functions show up whenever one quantity is divided by another: cost per item, time per trip, medicine per liter of blood. The asymptotes tell you what can never happen and what the long run looks like.

This shows up everywhere

  • Average cost, drug concentration over time, and how long a job takes as more workers join.
  • Lesson 3.6: inverse variation y = k/x is the graph of y = 1/x stretched by k.
  • In calculus, asymptotes become limits: the value f(x) approaches as x approaches a number or infinity.

Mini Knowledge Test

Show what you know — 5 quick questions

Question 1
Find all vertical asymptotes of f(x) = (x + 5)/(x² − 9).
Here's why: x² − 9 = (x − 3)(x + 3), and neither factor cancels with x + 5. So x = 3 and x = −3. x = −5 is the x-intercept (it comes from the numerator), “3 only” forgets the negative root, and ±9 forgets to take the square root.
Question 2
What is the horizontal asymptote of f(x) = (4x³ − x)/(2x³ + 7)?
Here's why: Equal degrees (3 and 3), so y = 4/2 = 2. y = ½ divides the coefficients upside down, and y = 0 is only for a bigger bottom degree.
Question 3
Where is the hole in the graph of f(x) = (x² + 2x − 15)/(x − 3)?
Here's why: (x + 5)(x − 3)/(x − 3) = x + 5 with x ≠ 3. Plug 3 into x + 5: 8. The hole is (3, 8). A hole is not automatically on the x-axis, and (−5, 0) is the x-intercept.
Question 4
What are the asymptotes of f(x) = 1/(x − 4) + 2?
Here's why: This is y = 1/x moved right 4 and up 2, so the asymptotes move too: x = 4 and y = 2. x = −4 flips the sign of the inside shift.
Question 5
A company's average cost per item is C̄(x) = (8x + 2400)/x. As x grows very large, what happens to the average cost?
Here's why: Top and bottom both have degree 1, so the horizontal asymptote is y = 8/1 = 8. The fixed $2,400 gets spread over more and more items. $300 is 2400 ÷ 8, and $0 uses the bigger-bottom rule.
