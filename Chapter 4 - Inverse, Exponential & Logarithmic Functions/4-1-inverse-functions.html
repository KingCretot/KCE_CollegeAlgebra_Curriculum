Let's Begin

An inverse undoes what the function did

A weather app shows 25°C, and you want Fahrenheit. Then a friend texts 77°F, and you want Celsius. The second formula runs the first one backward. That backward function is the inverse function, and it only exists when every output comes from exactly one input.

Today you'll decide when a function has an inverse, find the inverse with algebra, check it with composition, and see how its graph mirrors the original.

By the end of today, you will be able to:

  • 1Decide whether a function is one-to-one using the horizontal line test or the algebra test f(a) = f(b) ⇒ a = b
  • 2Verify that two functions are inverses by showing f(g(x)) = x and g(f(x)) = x
  • 3Find f⁻¹(x) by swapping x and y, restricting the domain when needed, and graph it as a reflection over y = x
  • 4Find the inverse of a function given as ordered pairs or a table, and state how the domains and ranges of f and f⁻¹ trade places

Vocabulary

The words for this lesson

One-to-One Function

A function where different inputs always give different outputs. No y-value is used twice.

💡Example: f(x) = x³ is one-to-one; f(x) = x² is not, because f(−2) = f(2) = 4.
Horizontal Line Test

A function is one-to-one exactly when no horizontal line crosses its graph more than once.

💡Memory hook: vertical line test asks “is it a function?” Horizontal line test asks “does it have an inverse?”
Inverse Function

f⁻¹ reverses f: if f(a) = b, then f⁻¹(b) = a. Domain and range trade places.

💡Watch the sign: f⁻¹(x) is not 1/f(x). The −1 is a label, not an exponent.
Reflection over y = x

The graph of f⁻¹ is the graph of f flipped across the line y = x. Every point (a, b) becomes (b, a).

💡Direction: the point (1, 5) on f becomes (5, 1) on f⁻¹.
y = x² fails: the line y = 4 hits it twice
y = x³ passes: every horizontal line hits once

How It Works

Finding an inverse in four moves

1
Check one-to-one
Use the horizontal line test, or show f(a) = f(b) forces a = b. If it fails, restrict the domain first or there is no inverse.
2
Replace f(x) with y
Write the function as an equation: y = 2x − 4.
3
Swap x and y, then solve for y
x = 2y − 4, so x + 4 = 2y and y = (x + 4)/2.
4
Rename and check
Write f⁻¹(x) = (x + 4)/2. Check: f(f⁻¹(x)) = 2 · (x + 4)/2 − 4 = x. The domain of f⁻¹ is the range of f.
f(x) = 2x − 4 (blue), f⁻¹(x) = (x + 4)/2 (red)

💭 Notice: The two graphs meet on the line y = x, here at (4, 4). Any point where f crosses y = x is also on f⁻¹.

Real-World Context

Celsius to Fahrenheit and back

The formula F(C) = (9/5)C + 32 turns Celsius into Fahrenheit. It is linear with a nonzero slope, so it passes the horizontal line test and has an inverse. Solve F = (9/5)C + 32 for C: F − 32 = (9/5)C, so C(F) = (5/9)(F − 32).

Example: Your friend's 77°F: C = (5/9)(77 − 32) = (5/9)(45) = 25. It is 25°C, the same temperature the app showed. The inverse undid the original exactly.

Worked Example · One-to-One by Algebra

Is f(x) = −4x + 12 one-to-one? Is g(x) = √(25 − x²)?

1
The algebra test
A function is one-to-one when f(a) = f(b) forces a = b. Assume f(a) = f(b) and see whether the algebra leads to a = b.
2
f(x) = −4x + 12
−4a + 12 = −4b + 12. Subtract 12: −4a = −4b. Divide by −4: a = b. So f is one-to-one.
3
g(x) = √(25 − x²)
√(25 − a²) = √(25 − b²). Square both sides: 25 − a² = 25 − b², so a² = b² and a = ±b. The ± lets two different inputs share an output: g(3) = √16 = 4 and g(−3) = √16 = 4. So g is not one-to-one.

💭 Notice: One example of two different inputs with the same output is enough to show a function is not one-to-one. To show it is one-to-one, you need the algebra (or the horizontal line test) for every input.

Worked Example · Ordered Pairs and Tables

Find the inverse of a function given as ordered pairs or a table

1
Ordered pairs: swap each pair
F = {(−2, 1), (0, 3), (1, 6), (4, 7)} never repeats an output, so it is one-to-one. Swap the coordinates in every pair: F⁻¹ = {(1, −2), (3, 0), (6, 1), (7, 4)}.
2
Domain and range trade places
Domain of F = {−2, 0, 1, 4} = range of F⁻¹. Range of F = {1, 3, 6, 7} = domain of F⁻¹. This is true for every inverse: the domain of f⁻¹ is the range of f, and the range of f⁻¹ is the domain of f.
3
Check for a repeated output first
G = {(−1, 5), (2, 5), (3, 8)} uses the output 5 twice. Swapping gives (5, −1) and (5, 2), one input with two outputs, so G has no inverse function.
4
From a table
The one-to-one function f is given by the table below. To find f⁻¹(7), find 7 in the f(x) row and read the x above it: f⁻¹(7) = 3. Swapping the two rows gives a table for f⁻¹.
x1234
f(x)−13711

💭 Common slip: f⁻¹(7) is not 1/7 and it is not f(7). It asks which input f sends to 7.

Worked Example · Verify by Composition

Are f(x) = 4x − 5 and g(x) = (x + 5)/4 inverses?

1
Compute f(g(x))
f((x + 5)/4) = 4 · (x + 5)/4 − 5 = x + 5 − 5 = x
2
Compute g(f(x))
g(4x − 5) = ((4x − 5) + 5)/4 = 4x/4 = x
3
Conclusion
Both compositions give x, so yes, g = f⁻¹.

💭 Notice: You need both directions. Checking only f(g(x)) = x can miss a domain problem, so always show g(f(x)) = x too.

Worked Example · Swap and Solve

Find f⁻¹(x) for f(x) = (2x + 1)/(x − 3)

1
Swap x and y
y = (2x + 1)/(x − 3) becomes x = (2y + 1)/(y − 3).
2
Clear the fraction and collect y
x(y − 3) = 2y + 1, so xy − 3x = 2y + 1, then xy − 2y = 3x + 1, and y(x − 2) = 3x + 1.
3
Solve
f⁻¹(x) = (3x + 1)/(x − 2), x ≠ 2. Note that f has domain x ≠ 3 and range y ≠ 2, and the inverse swaps them.

💭 Common slip: Move every y-term to one side before you factor. Students often stop at y = (3x + 1 + 2y)/x, which still has y on both sides.

Worked Example · Restrict the Domain

Find the inverse of f(x) = (x − 2)², x ≥ 2

1
Why restrict?
The full parabola fails the horizontal line test. Keeping only x ≥ 2 (the right half) makes it one-to-one, with range [0, ∞).
2
Swap and solve
x = (y − 2)², so √x = y − 2. Take the positive root because y ≥ 2.
3
Write the inverse
f⁻¹(x) = √x + 2, x ≥ 0. Its domain [0, ∞) is the range of f, and its range [2, ∞) is the domain of f.
f(x) = (x − 2)², x ≥ 2, and f⁻¹(x) = √x + 2

💭 Common slip: Writing ±√x gives two outputs, so it is not a function. The restricted domain tells you which sign to keep.

Your Turn — Guided Practice

Now you try, with me right here

Work each one, then tap your answer.

Question 1 — Find the inverse of f(x) = 5x − 2.

Here's why: Swap: x = 5y − 2, so x + 2 = 5y and y = (x + 2)/5. The answer x/5 + 2 undoes the steps in the wrong order: f multiplies by 5 and then subtracts 2, so the inverse must add 2 first and then divide by 5.

Question 2 — A one-to-one function has f(4) = 9. What is f⁻¹(9)?

Here's why: An inverse sends the output back to its input: f(4) = 9 means f⁻¹(9) = 4. The answer 1/9 treats f⁻¹ as a reciprocal, but the −1 is not an exponent.

Question 3: Find the inverse of F = {(−2, 5), (1, 3), (4, 2)}.

Here's why: F never repeats an output, so it has an inverse. Swap the coordinates in each pair: (−2, 5) becomes (5, −2), (1, 3) becomes (3, 1), and (4, 2) becomes (2, 4). The first choice takes reciprocals of the outputs, which reads the −1 in F⁻¹ as an exponent.

Why This Matters

Inverses are how you solve for the input

Any time you know the result and need the starting value, you are using an inverse. That is exactly why this lesson opens Chapter 4: the logarithm is defined as the inverse of an exponential function.

This shows up everywhere

  • Lesson 4.3 defines loga x as the inverse of ax, and its graph is the reflection over y = x.
  • Unit conversions (Celsius and Fahrenheit, dollars and euros) are function and inverse pairs.
  • Codes and encryption: one function scrambles a message and its inverse unscrambles it.

Mini Knowledge Test

Show what you know — 8 quick questions

Question 1
Which function is one-to-one?
Here's why: x³ − 2 always increases, so every horizontal line hits it once. The others repeat outputs: x² − 4 and x⁴ + 3 give the same value at x = 1 and x = −1, and |x + 1| gives 1 at both x = 0 and x = −2.
Question 2
Find f⁻¹(x) for f(x) = (x − 7)/3.
Here's why: Swap: x = (y − 7)/3, so 3x = y − 7 and y = 3x + 7. 3x − 7 keeps the wrong sign, (x + 7)/3 undoes in the wrong order, and 3/(x − 7) is the reciprocal.
Question 3
Find f⁻¹(x) for f(x) = ∛(x + 4).
Here's why: Swap: x = ∛(y + 4). Cube both sides: x³ = y + 4, so y = x³ − 4. (x − 4)³ subtracts before cubing (wrong order), and 1/∛(x + 4) is the reciprocal, not the inverse.
Question 4
The point (−3, 5) is on the graph of a one-to-one function f. Which point must be on the graph of f⁻¹?
Here's why: Reflecting over y = x swaps the coordinates: (a, b) becomes (b, a), so (−3, 5) becomes (5, −3). The other choices change signs instead of swapping places.
Question 5
Find the inverse of f(x) = x² + 3, x ≥ 0.
Here's why: Swap: x = y² + 3, so y² = x − 3 and y = √(x − 3), taking the positive root because the original domain was x ≥ 0. The range of f is [3, ∞), so the inverse has domain x ≥ 3. √x − 3 takes the root too early, and −√(x − 3) keeps the wrong sign.
Question 6
Ana tests g(x) = √(25 − x²) by setting g(a) = g(b). Squaring gives 25 − a² = 25 − b², so a² = b². What should she conclude?
Here's why: a² = b² means a = b or a = −b, so two different inputs can share an output: g(3) = √16 = 4 and g(−3) = √16 = 4. That one example proves g is not one-to-one. Writing only a = b drops the negative root. “Each x gives exactly one y” only says g is a function. Seeing a = −b and still calling it one-to-one misses the point: a = −b allows different inputs with the same output.
Question 7
A one-to-one function f has domain [−2, ∞) and range (−∞, 5]. What are the domain and range of f⁻¹?
Here's why: An inverse swaps every (a, b) to (b, a), so the domain and range trade places: the domain of f⁻¹ is the range of f, (−∞, 5], and the range of f⁻¹ is the domain of f, [−2, ∞). The second choice keeps them unchanged, and the last two change signs instead of swapping.
Question 8
The table gives the one-to-one function f. What is f⁻¹(2)?

Here's why: f⁻¹(2) asks which input f sends to 2. In the f(x) row, 2 sits under x = 0, so f⁻¹(2) = 0. 1/2 is a reciprocal, not an inverse. 9 is f(2), the function itself. −2 just changes the sign.

Debrief

What we learned today

You can use the horizontal line test or the algebra test f(a) = f(b) ⇒ a = b to decide whether a function is one-to-one.
You can verify inverses by showing both compositions equal x.
You can find f⁻¹(x) by swapping and solving, restrict a domain when needed, and sketch f⁻¹ as a reflection over y = x.
You can invert a set of ordered pairs or a table, and you know the domain of f⁻¹ is the range of f and the range of f⁻¹ is the domain of f.
