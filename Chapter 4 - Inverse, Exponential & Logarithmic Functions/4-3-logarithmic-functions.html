Let's Begin

A logarithm is an exponent

A bacteria colony doubles every hour. How many hours until it is 64 times bigger? You need the exponent in 2t = 64. The tool that hands you that exponent is the logarithm: log2 64 asks “2 to what power gives 64?”

Today you'll switch between log form and exponential form, solve simple log equations, graph log functions, and use the log properties to expand and condense.

By the end of today, you will be able to:

  • 1Convert between y = loga x and ay = x and solve simple logarithmic equations
  • 2Graph y = loga x as the reflection of y = ax, with domain x > 0 and asymptote x = 0, rising when a > 1 and falling when 0 < a < 1
  • 3Use the product, quotient, and power properties to expand and condense logarithms
  • 4Evaluate logarithms with the inverse properties and with given log values

Vocabulary

The words for this lesson

Logarithm

For a > 0, a ≠ 1, and x > 0: y = loga x means ay = x. The log is the exponent.

💡Memory hook: the base of the log is the base of the power: log3 9 = 2 because 3² = 9.
Logarithmic Function

f(x) = loga x, the inverse of f(x) = ax. Domain (0, ∞), range (−∞, ∞).

💡Watch the sign: you cannot take the log of 0 or a negative number. log2(−4) is undefined.
Vertical Asymptote x = 0

The graph of loga x hugs the y-axis but never touches it. It passes through (1, 0) and (a, 1).

💡Example: loga 1 = 0 for every base, because a0 = 1.
Properties of Logarithms

Product: loga(xy) = loga x + loga y. Quotient: loga(x/y) = loga x − loga y. Power: loga xr = r loga x.

💡Memory hook: they are the exponent rules in disguise: multiplying adds exponents, so logs of products add.
Inverse Properties

For a > 0, a ≠ 1: aloga x = x (for x > 0) and loga ax = x. Also loga 1 = 0 and loga a = 1.

💡Memory hook: ax and loga x undo each other, the same way f and f⁻¹ do in Lesson 4.1.

How It Works

Reading and graphing a logarithm

1
Convert the form
loga x = y and ay = x say the same thing. The base stays the base; the log value is the exponent.
2
Evaluate by asking a question
log5 125 asks “5 to what power is 125?” Answer 3. log5(1/25) = −2, because 5−2 = 1/25.
3
Graph by swapping points
Take points on y = 2x and swap them: (0, 1) becomes (1, 0) and (1, 2) becomes (2, 1), giving y = log2 x. The asymptote y = 0 becomes x = 0.
4
Shifts move the asymptote
loga(x − h) + k has vertical asymptote x = h and domain (h, ∞). To find the domain, solve inside > 0.
log2 x (blue) mirrors 2x (red) over y = x
y = log2(x + 3): asymptote x = −3

💭 Notice: The exponential has a horizontal asymptote and all real inputs. The log has a vertical asymptote and only positive inputs. Swapping x and y swaps those facts.

Real-World Context

How many doublings?

Back to the colony that doubles every hour. After t hours it is 2t times its original size. To find when it reaches 64 times its size, solve 2t = 64. In log form, t = log2 64.

Example: 26 = 64, so log2 64 = 6. The colony is 64 times larger after 6 hours.

Worked Example · Simple Log Equations

Solve three log equations by converting

1
logx 49 = 2
Exponential form: x² = 49, so x = ±7. A base must be positive, so x = 7.
2
log4 x = 5/2
Exponential form: x = 45/2 = (√4)5 = 25 = 32.
3
log1/2 8 = y
Exponential form: (1/2)y = 8. Since 1/2 = 2−1, 2−y = 2³, so y = −3.

💭 Common slip: The base goes with the power on the other side: log4 x = 5/2 means 45/2 = x, not (5/2)4 = x.

Worked Example · Graph With 0 < a < 1

Graph y = log1/2 x

1
Rewrite in exponential form
y = log1/2 x means (1/2)y = x. Choose y-values and compute x: y = 2 gives x = 1/4, y = 1 gives x = 1/2, y = 0 gives x = 1, y = −1 gives x = 2, and y = −2 gives x = 4.
2
Plot and connect
Plot (1/4, 2), (1/2, 1), (1, 0), (2, −1), (4, −2). The curve hugs the y-axis as x gets close to 0, so the vertical asymptote is x = 0.
3
Describe it
Domain (0, ∞), range (−∞, ∞). Because the base 1/2 is between 0 and 1, the graph falls from left to right (decreasing). It is the reflection of y = (1/2)x over y = x.
y = log1/2 x falls left to right; asymptote x = 0

💭 Notice: Every log graph passes through (1, 0) and (a, 1). With a = 1/2 the point (a, 1) is (1/2, 1), to the left of (1, 0), which is why the graph goes down.

Worked Example · Expanding

Expand log5(x³√y / z²)

1
Quotient property
log5(x³√y) − log5 z²
2
Product property
log5 x³ + log5 y1/2 − log5 z², writing √y as y1/2.
3
Power property
3 log5 x + ½ log5 y − 2 log5 z (for x, y, z > 0)

💭 Common slip: There is no rule for loga(x + y). Only products, quotients, and powers break apart.

Worked Example · Condensing

Write 2 log3 x − log3 y + 4 log3 z as one logarithm

1
Power property first
Move each coefficient up as an exponent: log3 x² − log3 y + log3 z4.
2
Combine the sums
log3 x² + log3 z4 = log3(x²z4).
3
Combine the difference
Subtracting a log divides: log3(x²z4/y).

💭 Notice: The same moves simplify numbers: log2 24 − log2 3 = log2(24/3) = log2 8 = 3.

Worked Example · Inverse Properties

Evaluate with the inverse properties

1
aloga x = x
7log7 10 = 10. log7 10 is the exponent that turns 7 into 10, so raising 7 to it gives 10.
2
loga ax = x
log5 54 = 4. The same idea evaluates log3 81: write 81 = 34, so log3 81 = log3 34 = 4.
3
loga 1 = 0 and loga a = 1
log9 1 = 0 because 90 = 1, and log12 12 = 1 because 121 = 12.
4
Put them together
4log4 5 + 2 log3 3 − log6 1 = 5 + 2(1) − 0 = 7.

💭 Common slip: The base of the power must match the base of the log. 2log3 5 is not 5, because 2 and 3 do not undo each other.

Worked Example · Using Given Log Values

Given log 2 ≈ 0.3010 and log 3 ≈ 0.4771, find each log

log with no base written means base 10 (more in Lesson 4.4). The plan: factor the number into 2s and 3s, then use the properties.

1
log 18
18 = 2 · 3², so log 18 = log 2 + 2 log 3 ≈ 0.3010 + 2(0.4771) = 1.2552.
2
log (3/2)
Quotient property: log 3 − log 2 ≈ 0.4771 − 0.3010 = 0.1761.
3
log √2
√2 = 21/2, so log √2 = ½ log 2 ≈ ½(0.3010) = 0.1505.
4
log 5
5 = 10/2 and log 10 = 1, so log 5 = log 10 − log 2 ≈ 1 − 0.3010 = 0.6990.

💭 Common slip: log 18 is not (log 2)(log 3)², and log(3/2) is not log 3 / log 2. A product inside the log becomes a sum, and a quotient becomes a difference. And log(2 + 3) is not log 2 + log 3: there is no rule for the log of a sum.

Your Turn — Guided Practice

Now you try, with me right here

Work each one, then tap your answer.

Question 1: Write 34 = 81 in logarithmic form.

Here's why: The base of the power becomes the base of the log, and the exponent is the log value: log3 81 = 4. The other choice swaps the base and the exponent; 43 is 64, not 81.

Question 2: Evaluate log2(1/16).

Here's why: 1/16 = 1/24 = 2−4, so log2(1/16) = −4. The answer 4 drops the negative; a reciprocal always means a negative exponent.

Question 3: Given log 2 ≈ 0.3010 and log 3 ≈ 0.4771, find log 36.

Here's why: 36 = 2² · 3², so log 36 = 2 log 2 + 2 log 3 ≈ 0.6020 + 0.9542 = 1.5562. 0.7781 is log 6, which forgets the squares. 0.6054 is (log 6)²: the power property puts the exponent in front as a multiplier, it does not square the log.

Question 4: Write 3 log2 x − ½ log2 y as a single logarithm.

Here's why: Power property first: log2 x³ − log2 y1/2. A difference of logs is the log of a quotient: log2(x³ / √y). The first choice subtracts inside the log, but subtracting logs divides their arguments.

Question 5: Evaluate 6log6 11 + log4 1.

Here's why: Inverse property: 6log6 11 = 11. And log4 1 = 0 because 40 = 1. The total is 11 + 0 = 11. 12 uses log4 1 = 1, which mixes it up with log4 4 = 1. 66 multiplies 6 by 11, but the 6 and the log6 undo each other.

Why This Matters

Logs bring the exponent down where you can reach it

Exponential models answer “how much after t years?” Logarithms answer the reverse: “how many years until?” The properties from today are the main tool for every equation in the rest of the chapter.

This shows up everywhere

  • Lesson 4.4 adds the common log (base 10) and natural log (base e), and uses them for pH and decibels.
  • Lesson 4.5 uses the power property to solve equations like 5x = 12, where the bases do not match.
  • Lesson 4.6 finds half-life and doubling time, which are always logarithms.

Mini Knowledge Test

Show what you know: 8 quick questions

Question 1
Which equation is the exponential form of log5(1/125) = −3?
Here's why: The base 5 stays the base and the log value −3 is the exponent: 5−3 = 1/125. The other choices put the base, exponent, and result in the wrong places.
Question 2
Solve log3(x − 1) = 2.
Here's why: Exponential form: 3² = x − 1, so 9 = x − 1 and x = 10. x = 9 forgets to add the 1, x = 8 subtracts it instead, and x = 7 multiplies 3 · 2 instead of squaring.
Question 3
What is the domain of f(x) = log2(x + 4)?
Here's why: The inside must be positive: x + 4 > 0, so x > −4. The bracket [−4 wrongly includes x = −4, where you would take log2 0. (4, ∞) flips the sign of the shift.
Question 4
Expand logb(x5√y).
Here's why: Product property, then power property: logb x5 + logb y1/2 = 5 logb x + ½ logb y. The log of a product is a sum, not a product, and the ½ belongs only to y.
Question 5
Simplify log2 40 − log2 5.
Here's why: Quotient property: log2(40/5) = log2 8 = 3. 8 stops before taking the log, log2 35 subtracts inside, and log2 200 multiplies.
Question 6
Given log 2 ≈ 0.3010 and log 3 ≈ 0.4771, find log 12.
Here's why: 12 = 2² · 3, so log 12 = 2 log 2 + log 3 ≈ 0.6020 + 0.4771 = 1.0791. 0.2872 multiplies the logs, 2(0.3010)(0.4771), but a product inside the log becomes a sum. 0.7781 is log 6, which forgets the square on 2. 1.5562 doubles both logs, which is log 36.
Question 7
Evaluate 3log3 8 − log5 5².
Here's why: Inverse properties: 3log3 8 = 8 and log5 5² = 2, so the value is 8 − 2 = 6. 22 treats 3log3 8 as 3 · 8 = 24. −17 treats log5 5² as 25. 3 treats log5 5² as 5.
Question 8
Which statement describes the graph of y = log1/3 x?
Here's why: The base 1/3 is between 0 and 1, so the graph falls. Every log graph passes through (1, 0), and log1/3 3 = −1 because (1/3)−1 = 3. (0, 1) and the asymptote y = 0 belong to the exponential y = (1/3)x, not the log. A log graph has vertical asymptote x = 0.
