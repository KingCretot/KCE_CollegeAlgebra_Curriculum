Let's Begin

Get the variable out of the exponent

How long until a savings account reaches $8,000? How many hours until a medicine drops to a safe level? In both, the unknown sits in an exponent, and you cannot reach it by adding or dividing. Taking a logarithm of both sides brings the exponent down where you can solve for it.

Today you'll solve exponential equations with logs, handle equations in quadratic form, solve log equations while rejecting extraneous solutions, and solve a formula for a variable in an exponent.

By the end of today, you will be able to:

  • 1Solve exponential equations by taking a logarithm of both sides
  • 2Solve logarithmic equations, including log M = log N ⇒ M = N, and reject extraneous solutions
  • 3Solve equations in quadratic form and formulas like A = Pert for a variable

Vocabulary

The words for this lesson

Log of Both Sides

If x = y with x, y > 0, then ln x = ln y. The power rule then moves the exponent down: ln ax = x ln a.

💡Memory hook: take the log, and the exponent falls out front.
Exact vs. Approximate

An exact solution keeps the logs, like x = ln 12 / ln 3. An approximate solution is its rounded decimal, like x ≈ 2.26.

💡Watch the rounding: round only at the very last step.
Quadratic in Form

An equation like e2x − 2ex − 8 = 0, where e2x = (ex)². Let u = ex and factor.

💡Watch the sign: ex is always positive, so ex = −2 has no solution.
Extraneous Solution

A value that solves a rewritten equation but not the original, usually because it makes a log’s argument zero or negative.

💡Memory hook: every log equation ends with a check.

How It Works

Two kinds of equations, two game plans

1
Isolate the exponential
Get a(stuff) or e(stuff) alone on one side. Divide or subtract first.
2
Take ln of both sides
Use the power rule to bring the exponent down, then solve the resulting linear equation.
3
Log equations: condense, then convert
Combine the logs into a single log, then rewrite loga M = c as M = ac.
4
Check the domain
Substitute each answer into the original equation. Reject any value that makes a log’s argument ≤ 0.
2x = 10 where the curve meets y = 10: x = ln 10 / ln 2 ≈ 3.32

💭 Notice: Every solution of an exponential equation is a logarithm. The answer to 2x = 10 is exactly x = log2 10.

Real-World Context

How long until the money grows?

Continuous compounding uses A = Pert. Solve it for t first: divide by P to get A/P = ert, take ln of both sides to get ln(A/P) = rt, then divide by r: t = ln(A/P) / r. Suppose $5,000 earns 4.5% interest compounded continuously. How long until it reaches $8,000?

Example: t = ln(8000/5000) / 0.045 = ln 1.6 / 0.045 ≈ 0.4700 / 0.045 ≈ 10.44. To the nearest hundredth, it takes about 10.44 years.

Worked Example · Exponential Equation

Solve 52x − 1 = 40

1
Take ln of both sides
ln 52x − 1 = ln 40, so (2x − 1) ln 5 = ln 40
2
Solve for x
2x − 1 = ln 40 / ln 5, so x = (ln 40 / ln 5 + 1) / 2. That is the exact solution.
3
Approximate
ln 40 / ln 5 ≈ 2.2920, so x ≈ (2.2920 + 1) / 2 ≈ 1.6460. To the nearest hundredth, x ≈ 1.65.

💭 Common slip: Keep the parentheses: (2x − 1) ln 5, not 2x − 1 · ln 5. The whole exponent gets multiplied by ln 5.

Worked Example · Quadratic in Form

Solve e2x − 2ex − 8 = 0

1
Substitute u = ex
e2x = (ex)², so the equation is u² − 2u − 8 = 0
2
Factor
(u − 4)(u + 2) = 0, so ex = 4 or ex = −2. Since ex > 0 always, reject −2.
3
Solve with ln
x = ln 4 ≈ 1.386. To the nearest hundredth, x ≈ 1.39.

💭 Common slip: Factoring gives two values of u, not of x. Go back to ex = u and take ln. Writing x = 4 skips that last step.

Worked Example · Log Equation

Solve log2 x + log2(x − 6) = 4

1
Condense
Product rule: log2[x(x − 6)] = 4
2
Convert and solve
x(x − 6) = 24 = 16, so x² − 6x − 16 = 0 and (x − 8)(x + 2) = 0. Candidates: x = 8 or x = −2.
3
Check
x = −2 gives log2(−2), which is undefined, so it is extraneous. x = 8: log2 8 + log2 2 = 3 + 1 = 4. The solution is x = 8.
y = log2 x + log2(x − 6) meets y = 4 only at x = 8

💭 Notice: The left side only exists for x > 6, so the graph never reaches x = −2. That is why −2 fails the check.

Worked Example · log M = log N

Solve log(x + 6) − log(x + 2) = log x

1
Condense the left side
Quotient property: log[(x + 6)/(x + 2)] = log x. Now there is one log on each side, with the same base.
2
Set the arguments equal
Logarithms are one-to-one, so log M = log N means M = N: (x + 6)/(x + 2) = x. Multiply by x + 2: x + 6 = x² + 2x.
3
Solve the quadratic
x² + x − 6 = 0, so (x + 3)(x − 2) = 0. Candidates: x = −3 or x = 2.
4
Check the domain
x = −3 gives log(−3 + 2) = log(−1), which is undefined, so reject it. x = 2: log 8 − log 4 = log 2, and log(8/4) = log 2. The solution set is {2}.

💭 Common slip: Do not subtract the arguments: log(x + 6) − log(x + 2) is not log[(x + 6) − (x + 2)]. Subtracting logs divides the arguments.

Your Turn — Guided Practice

Now you try, with me right here

Work each one, then tap your answer.

Question 1 — Solve e0.3x = 12 to the nearest hundredth.

Here's why: Take ln of both sides: 0.3x = ln 12 ≈ 2.4849, so x ≈ 2.4849 / 0.3 ≈ 8.28. 3.60 uses log 12 instead of ln 12. With base e, only ln undoes the exponent.

Question 2 — Solve log x + log(x + 3) = 1.

Here's why: Condense: log[x(x + 3)] = 1, so x² + 3x = 10 and (x + 5)(x − 2) = 0. x = −5 makes log(−5) undefined, so it is extraneous. Only x = 2 works. Keeping −5 skips the domain check.

Question 3: Solve log3(x + 7) = log3(2x − 1).

Here's why: Same base on both sides, so set the arguments equal: x + 7 = 2x − 1, which gives x = 8. Check: 8 + 7 = 15 and 2(8) − 1 = 15, both positive. Subtract x from both sides: 7 = x − 1. {6} comes from subtracting 1 here instead of adding it.

Why This Matters

Logs undo exponents, and that unlocks every model

Any time a quantity grows or shrinks by a percentage, the question “when will it reach this level?” becomes an exponential equation. Today’s steps are exactly how those questions get answered.

This shows up everywhere

  • Finance: how long until an investment doubles, or until a loan balance falls below a target.
  • Lesson 4.6 uses these steps to find growth rates, half-lives, and doubling times.
  • Science: solving A = A0ekt for t is how carbon dating and drug dosing work.

Mini Knowledge Test

Show what you know — 6 quick questions

Question 1
Solve 3x − 2 = 50 to the nearest hundredth.
Here's why: (x − 2) ln 3 = ln 50, so x = 2 + ln 50 / ln 3 ≈ 2 + 3.5609 = 5.56. 3.56 forgets to add the 2, 1.56 subtracts it, and 18.67 divides 50 by 3 and adds 2 instead of using logs.
Question 2
Solve 4x = 3x + 1 to the nearest hundredth.
Here's why: x ln 4 = (x + 1) ln 3, so x ln 4 − x ln 3 = ln 3 and x = ln 3 / (ln 4 − ln 3) ≈ 3.82. 0.79 drops the x on the right side, 0.44 adds ln 3 instead of subtracting, and −3.82 is a sign slip.
Question 3
Solve e2x − 7ex + 10 = 0.
Here's why: Let u = ex: (u − 2)(u − 5) = 0, so ex = 2 or 5, and x = ln 2 ≈ 0.69 or x = ln 5 ≈ 1.61. x = 2 or 5 stops before taking ln, 0.30 and 0.70 use log instead of ln, and “no solution” comes from factoring as (u + 2)(u + 5).
Question 4
Solve log3(x + 1) + log3(x − 1) = 1.
Here's why: log3[(x + 1)(x − 1)] = 1, so x² − 1 = 31 = 3 and x = ±2. x = −2 makes both arguments negative, so only x = 2 works. √2 comes from setting x² − 1 equal to 1 instead of 31.
Question 5
Solve A = Pert for t.
Here's why: Divide by P: A/P = ert. Take ln: ln(A/P) = rt. Divide by r: t = ln(A/P) / r. Subtracting P is not how you undo multiplying by P, and ln A / (Pr) takes ln before dividing out P.
Question 6
Solve ln(x + 4) − ln(x − 2) = ln x.
Here's why: Quotient property: ln[(x + 4)/(x − 2)] = ln x, so (x + 4)/(x − 2) = x. Then x + 4 = x² − 2x, so x² − 3x − 4 = 0 and (x − 4)(x + 1) = 0. x = −1 makes ln(x − 2) = ln(−3) undefined, so reject it; x = 4 checks: ln 8 − ln 2 = ln 4. {4, −1} skips the check, {−1} keeps the wrong root, and {6} subtracts the arguments instead of dividing.
