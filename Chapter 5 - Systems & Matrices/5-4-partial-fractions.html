Let's Begin

Adding fractions, run in reverse

In Lesson R.5 you added fractions like 2/(x + 1) + 3/(x − 2) into one fraction. Partial fraction decomposition undoes that: it splits one fraction back into the simple pieces it came from.

Today you'll set up the right form for a decomposition and find the unknown numerators with a system of equations.

By the end of today, you will be able to:

  • 1Choose the correct form for a partial fraction decomposition
  • 2Decompose fractions with distinct and repeated linear factors
  • 3Decompose fractions with an irreducible quadratic factor

Vocabulary

The words for this lesson

Partial Fraction Decomposition

Rewriting P(x)/Q(x) as a sum of fractions with simpler denominators.

💡Example: (5x − 1)/((x + 1)(x − 2)) = 2/(x + 1) + 3/(x − 2)
Proper Fraction

The degree of the top is less than the degree of the bottom. Only proper fractions can be decomposed directly.

💡If improper: Divide first, then decompose the remainder fraction.
Linear Factors

A distinct factor (ax + b) gets A/(ax + b). A repeated factor (ax + b)n gets one term for each power up to n.

💡Example: (x − 1)2 gives A/(x − 1) + B/(x − 1)2.
Irreducible Quadratic Factor

A quadratic that does not factor over the reals, like x2 + 1. It gets a linear numerator: (Bx + C)/(x2 + 1).

💡Check: ax2 + bx + c is irreducible when b2 − 4ac < 0.

How It Works

Decomposing a fraction

1
Check that it is proper
If the degree on top is at least the degree on the bottom, use long division first.
2
Factor the denominator completely
Into linear factors and irreducible quadratic factors.
3
Write the form
One term for each linear factor (and each power of a repeated one), and a (Bx + C) term for each irreducible quadratic.
4
Solve for the constants
Multiply both sides by the denominator. Substitute convenient x-values, or match coefficients and solve the system.

💭 Notice: Substituting the zeros of the linear factors is the fastest way to find constants. When that runs out, match the coefficients of each power of x.

Real-World Context

Why split a fraction?

Engineers analyzing a circuit or a spring often get a single complicated rational expression. Splitting it into simple pieces makes each piece easy to handle on its own, and it is a key step in calculus.

Example: A signal described by (5x − 1)/((x + 1)(x − 2)) is really two simpler parts added together: 2/(x + 1) and 3/(x − 2). Each part can be studied separately.

Worked Example · Distinct Linear

Decompose (5x − 1)/((x + 1)(x − 2))

1
Write the form
A/(x + 1) + B/(x − 2). Multiply by the denominator: 5x − 1 = A(x − 2) + B(x + 1).
2
Substitute the zeros
x = 2: 9 = 3B, so B = 3. x = −1: −6 = −3A, so A = 2.
3
Write the answer
2/(x + 1) + 3/(x − 2). Check: 2(x − 2) + 3(x + 1) = 5x − 1.

💭 Common slip: Choosing x = 2 makes the A term vanish, so B falls right out. That is why the zeros of the factors are the best values to try.

Worked Example · Repeated Linear

Decompose (3x + 5)/(x + 1)2

1
Write the form
A/(x + 1) + B/(x + 1)2. Multiply by (x + 1)2: 3x + 5 = A(x + 1) + B.
2
Match coefficients
x-terms: A = 3. Constants: A + B = 5, so B = 2.
3
Write the answer
3/(x + 1) + 2/(x + 1)2

💭 Common slip: A repeated factor needs a term for every power. A/(x + 1)2 alone cannot produce the 3x on top.

Worked Example · Quadratic Factor

Decompose (x2 + x + 2)/(x(x2 + 1))

1
Write the form
A/x + (Bx + C)/(x2 + 1). Multiply: x2 + x + 2 = A(x2 + 1) + (Bx + C)x.
2
Match coefficients
x2: A + B = 1. x: C = 1. Constant: A = 2. So B = −1.
3
Write the answer
2/x + (1 − x)/(x2 + 1). Check: 2x2 + 2 + x − x2 = x2 + x + 2.

💭 Common slip: x2 + 1 needs a linear numerator, Bx + C. A constant numerator alone would not have enough freedom to match the top.

Here's why: Each distinct linear factor gets its own term. A/((x − 3)(x + 4)) is just the original fraction with a new name on top.

Here's why: The degree on top (3) is larger than on the bottom (2), so the fraction is improper. Divide first, then decompose the remainder.

Mini Knowledge Test

Show what you know — 5 quick questions

Question 1
Decompose 7/((x − 3)(x + 4)).
Here's why: 7 = A(x + 4) + B(x − 3). x = 3 gives 7 = 7A, so A = 1. x = −4 gives 7 = −7B, so B = −1. 7/(x − 3) − 7/(x + 4) forgets to divide by 7.
Question 2
Decompose (4x + 1)/(x(x + 1)).
Here's why: 4x + 1 = A(x + 1) + Bx. x = 0 gives A = 1. x = −1 gives −3 = −B, so B = 3. Check: x + 1 + 3x = 4x + 1.
Question 3
What is the form for (2x + 1)/((x − 1)2(x + 2))?
Here's why: The repeated factor (x − 1)2 needs one term for each power, 1 and 2. The other choices skip a power or repeat the same power.
Question 4
What is the form for (x + 5)/((x + 1)(x2 + 4))?
Here's why: x2 + 4 is irreducible (it is a sum of squares), so it gets a linear numerator Bx + C. It does not factor as (x + 2)(x − 2); that is x2 − 4.
Question 5
In (x + 7)/((x − 1)(x + 3)) = A/(x − 1) + B/(x + 3), find A.
Here's why: x + 7 = A(x + 3) + B(x − 1). x = 1 gives 8 = 4A, so A = 2. −1 is B, 8 forgets to divide by 4, and 1/2 divides the wrong way.
