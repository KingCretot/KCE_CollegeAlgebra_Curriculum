Let's Begin

Finding the best choice inside the limits

A business has limits on time, money, and materials, and it wants the most profit inside those limits. Systems of inequalities describe the limits, and linear programming finds the best choice.

Today you'll graph inequalities and systems of inequalities, find the corner points of the solution region, and use them to maximize or minimize a quantity.

By the end of today, you will be able to:

  • 1Graph linear and nonlinear inequalities and systems of inequalities
  • 2Find the corner points of a feasible region
  • 3Maximize or minimize an objective function with linear programming

Vocabulary

The words for this lesson

Boundary Line

The line you get by replacing the inequality sign with =. Use a solid line for ≤ or ≥ and a dashed line for < or >. A nonlinear inequality has a boundary curve, like a parabola or circle, with the same rules.

💡Example: y < 2x − 1 has a dashed boundary y = 2x − 1.
Test Point

Pick a point not on the line, usually (0, 0). If it makes the inequality true, shade its side; if not, shade the other side.

💡Example: For x + y ≤ 6, (0, 0) gives 0 ≤ 6, true, so shade the side with the origin.
Feasible Region

The region where every inequality in the system is true: the overlap of all the shading.

💡Memory hook: Feasible means “possible.” Every point in the region is an allowed choice.
Objective Function

The quantity to maximize or minimize, such as profit P = 3x + 2y.

💡Key fact: Its maximum and minimum occur at corner points (vertices) of the feasible region.

How It Works

Solving a linear programming problem

1
Write the constraints
Turn each limit into an inequality. Include x ≥ 0 and y ≥ 0 when the amounts cannot be negative.
2
Graph the feasible region
Graph each boundary line and shade. The feasible region is where all the shading overlaps.
3
Find the corner points
Read them from the graph or solve the system of the two boundary lines that meet there.
4
Test every corner
Evaluate the objective function at each corner. The largest value is the maximum; the smallest is the minimum.

💭 Notice: Test every corner. The best corner is not always the one farthest from the origin.

Real-World Context

Scheduling a tutoring week

A tutor can teach at most 10 lessons a week. A group lesson takes 2 hours and a private lesson takes 1 hour, with 16 hours available. Group lessons earn $90 and private lessons $50. How many of each maximize revenue?

Example: Constraints: x + y ≤ 10, 2x + y ≤ 16, x ≥ 0, y ≥ 0. The corners are (0, 0), (8, 0), (6, 4), and (0, 10), with revenue $0, $720, $740, and $500. The best plan is 6 group and 4 private lessons for $740.

Worked Example · System of Inequalities

Graph the system x + y ≤ 6 and y ≥ x − 2

1
Graph the boundaries
Both are solid lines because of ≤ and ≥: y = 6 − x and y = x − 2.
2
Test (0, 0)
0 + 0 ≤ 6 is true, and 0 ≥ −2 is true, so the origin is in both regions.
3
Shade the overlap
The solution is the region below y = 6 − x and above y = x − 2. The lines meet at (4, 2).
x + y ≤ 6 and y ≥ x − 2: the region below one line and above the other

💭 Common slip: Use the test point on each inequality separately. A point can satisfy one inequality and not the other.

Worked Example · Nonlinear Inequalities

Graph the system y ≥ x2 − 4 and x2 + y2 ≤ 16

1
Graph the boundaries
y = x2 − 4 is a parabola with vertex (0, −4). x2 + y2 = 16 is a circle with center (0, 0) and radius 4. Both are solid because of ≥ and ≤.
2
Test (0, 0) in each
0 ≥ 0 − 4 is true, so shade above the parabola. 0 + 0 ≤ 16 is true, so shade inside the circle.
3
Shade the overlap
The solution is the region inside the circle and above the parabola. Substituting y = x2 − 4 into the circle gives x4 − 7x2 = 0, so the curves cross at (±√7, 3) and touch at (0, −4).
y ≥ x2 − 4 and x2 + y2 ≤ 16: the region inside the circle and above the parabola

💭 Notice: The test point works the same way for curves. Pick a point that is not on the boundary, usually (0, 0), and shade the side that makes the inequality true.

Worked Example · Maximize

Maximize P = 3x + 2y subject to x ≥ 0, y ≥ 0, x + y ≤ 8, and 2x + y ≤ 12

1
Find the corners
(0, 0), (6, 0), (0, 8), and where x + y = 8 meets 2x + y = 12: subtracting gives x = 4, so y = 4.
2
Evaluate P
P(0, 0) = 0, P(6, 0) = 18, P(4, 4) = 20, P(0, 8) = 16
3
Pick the largest
The maximum is P = 20 at (4, 4).
The feasible region has corners (0, 0), (6, 0), (4, 4), and (0, 8)

💭 Common slip: The corner where two slanted lines cross is easy to miss. It is often the best one, so solve for it every time.

Worked Example · Minimize

Minimize C = 2x + 5y subject to x ≥ 0, x ≤ 4, x + y ≥ 6, and y ≤ 8

1
Find the corners
(0, 6), (4, 2), (4, 8), and (0, 8)
2
Evaluate C
C(0, 6) = 30, C(4, 2) = 18, C(4, 8) = 48, C(0, 8) = 40
3
Pick the smallest
The minimum is C = 18 at (4, 2).
Corners (0, 6), (4, 2), (4, 8), and (0, 8)

💭 Common slip: For x + y ≥ 6, the origin fails the test (0 ≥ 6 is false), so shade away from the origin.

Work each one, then tap your answer.

Question 1: For y > 2x + 3, the test point (0, 0) gives 0 > 3. Which side do you shade?

Here's why: 0 > 3 is false, so the origin is not a solution. Shade the other side of the dashed line.

Question 2: Where does the maximum of a linear objective function occur?

Here's why: The value of a linear function keeps rising in one direction until it hits the edge of the region, so the best value is always at a vertex.

Question 3: How do you graph x2 + y2 < 9?

Here's why: < means points on the circle are not included, so the boundary is dashed. The test point (0, 0) gives 0 < 9, which is true, so shade the inside, where the origin is.

Mini Knowledge Test

Show what you know: 7 quick questions

Question 1
Which point satisfies both x + y < 5 and y > 1?
Here's why: (1, 2): 3 < 5 and 2 > 1. (4, 2) gives 6, not less than 5. (2, 0) and (3, 1) fail y > 1; for (3, 1), 1 > 1 is false because the inequality is strict.
Question 2
A feasible region has corners (0, 0), (5, 0), (3, 4), and (0, 5). Find the maximum of P = 2x + 3y.
Here's why: P(0, 0) = 0, P(5, 0) = 10, P(3, 4) = 6 + 12 = 18, and P(0, 5) = 15. The largest is 18.
Question 3
A feasible region has corners (0, 6), (2, 2), and (5, 0). Find the minimum of C = 4x + y.
Here's why: C(0, 6) = 6, C(2, 2) = 10, and C(5, 0) = 20, so the minimum is 6. (0, 0) is not a corner of this region, so it cannot be used.
Question 4
How do you graph y < 2x − 1?
Here's why: < uses a dashed line because points on the line are not solutions. y is less than the line, so shade below it.
Question 5
Find the corner point where x + 2y = 10 meets x − y = 1.
Here's why: Subtracting the equations gives 3y = 9, so y = 3, and then x = 4. (3, 4) swaps the coordinates, and (10, 0) and (1, 0) are each on only one of the lines.
Question 6
Which point is a solution of the system y ≥ x2 − 4 and x2 + y2 ≤ 16?
Here's why: (1, 2): 2 ≥ 1 − 4 = −3 is true, and 1 + 4 = 5 ≤ 16 is true. (2, −1) and (−3, 2) are inside the circle but below the parabola (−1 ≥ 0 and 2 ≥ 5 are false). (1, 4) is above the parabola but outside the circle, since 1 + 16 = 17.
Question 7
How do you graph y < x2 + 1?
Here's why: < means the boundary y = x2 + 1 is not included, so it is dashed. y is less than the curve, so shade below it. Check with (0, 0): 0 < 1 is true, and the origin is below the vertex (0, 1).
