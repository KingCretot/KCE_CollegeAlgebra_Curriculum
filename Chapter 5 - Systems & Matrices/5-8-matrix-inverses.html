Let's Begin

The matrix that undoes a matrix

For numbers, 5 · (1/5) = 1. For matrices, the identity matrix I plays the role of 1, and the inverse A−1 plays the role of 1/5. With an inverse, a whole system can be solved in one multiplication.

Today you'll find the inverse of a 2 × 2 matrix with a formula, find 2 × 2 and 3 × 3 inverses by row reduction, recognize matrices with no inverse, and solve systems with AX = B.

By the end of today, you will be able to:

  • 1Find the inverse of a 2 × 2 matrix with the formula
  • 2Find a 2 × 2 or 3 × 3 inverse by row-reducing [A | I]
  • 3Solve a system of two or three equations using X = A−1B

Vocabulary

The words for this lesson

Identity Matrix

The square matrix I with 1s on the main diagonal and 0s elsewhere. AI = IA = A.

💡Example: The 2 × 2 identity is [1 0; 0 1].
Inverse Matrix

A−1 is the matrix with AA−1 = A−1A = I. Only square matrices can have inverses.

💡Common slip: A−1 does not mean 1 divided by each entry.
2 × 2 Formula

For A = [a b; c d] with ad − bc ≠ 0, A−1 = (1/(ad − bc)) · [d −b; −c a].

💡Memory hook: Swap a and d, change the signs of b and c, divide by the determinant.
Singular Matrix

A square matrix with determinant 0. It has no inverse.

💡Example: [2 4; 1 2] has determinant 4 − 4 = 0, so it has no inverse.

Notation: to save space, a matrix is sometimes written on one line with its rows separated by semicolons. [1 2; 3 4] means the matrix with first row 1, 2 and second row 3, 4.

How It Works

Solving AX = B with an inverse

1
Write the system as AX = B
A holds the coefficients, X the variables, and B the constants.
2
Find A−1
Use the 2 × 2 formula or row-reduce [A | I] until it reads [I | A−1].
3
Multiply
X = A−1B. The order matters: A−1 goes on the left.
4
Check
Substitute the solution into the original equations.

💭 Notice: If row-reducing [A | I] produces a row of zeros on the left, A is singular and has no inverse.

Real-World Context

Secret messages

A simple code turns letters into numbers and multiplies them by a matrix A. Anyone with A−1 can multiply again and read the message; anyone without it sees only scrambled numbers.

Example: If a message pair was coded with A = [3 1; 5 2] and arrived as [11; 19], then A−1 = [2 −1; −5 3] decodes it: [2(11) − 19; −5(11) + 3(19)] = [3; 2], the letters C and B.

Worked Example · 2 × 2 Formula

Find the inverse of A = [3 1; 5 2]

1
Determinant
ad − bc = 3(2) − 1(5) = 1, which is not 0, so A has an inverse.
2
Swap and change signs
Swap 3 and 2; change the signs of 1 and 5: [2 −1; −5 3].
3
Divide by the determinant
Dividing by 1 changes nothing: A−1 = [2 −1; −5 3]. Check: AA−1 = [6 − 5, −3 + 3; 10 − 10, −5 + 6] = I.

Worked Example · Row Reduction

Find the inverse of A = [2 4; 1 3] by row-reducing [A | I]

1
Set up and swap
[2 4 | 1 0; 1 3 | 0 1]. Swap the rows to put a 1 in the corner.
2
Clear column 1, then column 2
R2 − 2R1 gives [0 −2 | 1 −2]. Divide by −2: [0 1 | −1/2 1]. Then R1 − 3R2 gives [1 0 | 3/2 −2].
3
Read A−1
A−1 = [3/2 −2; −1/2 1]. The formula agrees: (1/2)[3 −4; −1 2].

Worked Example · 3 × 3 Inverse

Find the inverse of A = [1 2 0; 0 1 1; 1 2 1] by row-reducing [A | I]

1
Set up [A | I]
Write A on the left and the 3 × 3 identity on the right. Column 1 already has a 1 on top.
2
Clear column 1
R3 − R1 gives [0 0 1 | −1 0 1]. Row 3 now has its 1 in column 3.
3
Clear column 3, then column 2
R2 − R3 gives [0 1 0 | 1 1 −1]. Then R1 − 2R2 gives [1 0 0 | −1 −2 2].
4
Read A−1
The left side is I, so the right side is A−1 = [−1 −2 2; 1 1 −1; −1 0 1]. Check: row 1 of A times column 1 of A−1 is 1(−1) + 2(1) + 0(−1) = 1.

Worked Example · Solving AX = B

Solve 3x + y = 5 and 5x + 2y = 9 using an inverse

1
Write AX = B
A = [3 1; 5 2], X = [x; y], B = [5; 9].
2
Use A−1 from Example 1
X = A−1B = [2 −1; −5 3][5; 9] = [10 − 9; −25 + 27]
3
Read the solution
X = [1; 2], so (1, 2). Check: 3 + 2 = 5 and 5 + 4 = 9.

💭 Common slip: Write A−1B, not BA−1. B is 2 × 1, so BA−1 is not even defined.

Worked Example · Three Variables with an Inverse

Solve x + 2y = 5, y + z = 5, and x + 2y + z = 8 using A−1

1
Write AX = B
The coefficient matrix is A = [1 2 0; 0 1 1; 1 2 1], the same A as the 3 × 3 example, and B = [5; 5; 8].
2
Multiply X = A−1B
Row 1: −1(5) − 2(5) + 2(8) = 1. Row 2: 1(5) + 1(5) − 1(8) = 2. Row 3: −1(5) + 0(5) + 1(8) = 3.
3
Read and check
X = [1; 2; 3], so the solution is (1, 2, 3). Check: 1 + 4 = 5, 2 + 3 = 5, and 1 + 4 + 3 = 8.

Your Turn — Guided Practice

Now you try, with me right here

Work each one, then tap your answer.

Question 1 — Does [2 4; 1 2] have an inverse?

Here's why: 2(2) − 4(1) = 0, so the matrix is singular. The formula would divide by 0.

Question 2 — What is AA−1?

Here's why: By definition, a matrix times its inverse is the identity, just as 5 · (1/5) = 1.

Question 3 — While row-reducing [A | I] for a 3 × 3 matrix A, the left side gets a row of all zeros. What does that tell you?

Here's why: If the left side cannot become I, there is no inverse. A row of zeros on the left means the determinant of A is 0, so A is singular.

Why This Matters

Undoing a matrix

Inverses decode messages, reverse computer-graphics transformations, and solve many systems with the same coefficients at once: find A−1 once, then multiply by each new B.

This shows up everywhere

  • Lesson 4.1 introduced inverse functions, which undo a function the same way.
  • Lesson 5.3 gave the determinant that decides whether an inverse exists.
  • Linear algebra courses build directly on AX = B.

Mini Knowledge Test

Show what you know — 7 quick questions

Question 1
Which matrix has no inverse?
Here's why: The determinant of [6 3; 4 2] is 12 − 12 = 0. The others have determinants 6, −2, and −1, all nonzero.
Question 2
Find the inverse of [4 7; 1 2].
Here's why: The determinant is 8 − 7 = 1. Swap 4 and 2 and change the signs of 7 and 1. The other choices skip the swap, negate everything, or skip the sign change.
Question 3
Find the inverse of [2 1; 4 3].
Here's why: The determinant is 6 − 4 = 2, so A−1 = (1/2)[3 −1; −4 2]. [3 −1; −4 2] forgets to divide by 2, and the others mix up the signs or the swap.
Question 4
If A−1 = [1 −1; −1 2] and B = [3; 5], solve AX = B.
Here's why: X = A−1B = [1(3) − 1(5); −1(3) + 2(5)] = [−2; 7]. (7, −2) swaps the variables, and (8, 13) ignores the negative entries.
Question 5
A 2 × 2 matrix has determinant 0. Which is true?
Here's why: The inverse formula divides by the determinant, so a determinant of 0 means there is no inverse at all. Such a matrix is called singular.
Question 6
If A−1 = [1 0 −1; −2 1 0; 0 −1 1] and B = [2; 1; 3], solve AX = B.
Here's why: X = A−1B: row 1 is 1(2) + 0(1) − 1(3) = −1, row 2 is −2(2) + 1(1) + 0(3) = −3, and row 3 is 0(2) − 1(1) + 1(3) = 2. (5, 5, 4) ignores the negative entries, (2, −3, −1) lists the values in reverse order, and (−1, −3, −4) subtracts 3 in row 3 instead of adding it.
Question 7
Which is the inverse of [1 0 0; 0 2 0; 0 0 −1]?
Here's why: Row-reducing [A | I] only needs R2 ÷ 2 and R3 ÷ (−1), so the inverse has 1, 1/2, and −1 on the diagonal. Check: 2 · (1/2) = 1 and (−1)(−1) = 1. Negating entries does not invert them, and the matrix itself gives 2 · 2 = 4, not 1.
