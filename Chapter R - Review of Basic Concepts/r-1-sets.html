Let's Begin

The language every other chapter is written in

Every answer in this course is a set: the solutions of an equation, the domain of a function, the points on a graph. Before you can write those answers, you need the vocabulary and notation for sets.

Today you'll read and write sets, decide when one set is a subset of another, and combine sets with union, intersection, and complement.

By the end of today, you will be able to:

  • 1Write sets in roster form and in set-builder notation
  • 2Identify subsets and count how many subsets a set has
  • 3Find the complement, intersection, and union of sets

Vocabulary

The words for this lesson

Set & Element

A set is a collection of objects. Each object is an element (or member). a ∈ A means “a is an element of A.”

💡Example: 5 ∈ {1, 3, 5, 7}, but 4 ∉ {1, 3, 5, 7}.
Empty Set

The set with no elements, written ∅ or { }.

💡Common slip: {∅} is not empty; it has one element, the empty set.
Subset

A ⊆ B means every element of A is also an element of B.

💡Memory hook: A set with n elements has 2n subsets, including ∅ and the set itself.
Union & Intersection

A ∪ B holds everything in A or B. A ∩ B holds only what is in A and B.

💡Memory hook: ∪ looks like a cup that holds everything; ∩ is the narrow overlap.

How It Works

Reading and combining sets

1
Roster form
List the elements inside braces: {2, 4, 6, 8}. Use … for a pattern that continues: {1, 2, 3, …}.
2
Set-builder notation
Describe the rule: {x | x is an even natural number less than 10}. Read the bar as “such that.”
3
Subsets
Check every element of A. If each one is in B, then A ⊆ B. If even one is missing, A ⊈ B.
4
Combine
Complement A′: everything in the universal set U that is not in A. Intersection: elements in both. Union: elements in either, listed once.

💭 Notice: Order and repeats do not matter in a set. {3, 1, 2} and {1, 2, 3, 3} are the same set.

Real-World Context

Which students qualify?

A tutoring center tracks two lists: S = students in SAT prep and A = students in Algebra 2. The center wants the students in both programs (to schedule them back to back) and the students in either program (for a newsletter).

Example: If S = {Ana, Ben, Cara, Dev} and A = {Ben, Dev, Eli}, then S ∩ A = {Ben, Dev} and S ∪ A = {Ana, Ben, Cara, Dev, Eli}. Ben and Dev are listed once in the union, not twice.

Worked Example · Set-Builder Notation

Write {x | x is a natural number between 3 and 9} in roster form

1
Read the rule
Natural numbers are 1, 2, 3, … “Between 3 and 9” means 3 and 9 themselves are left out.
2
List the elements
4, 5, 6, 7, 8
3
Write the set
{4, 5, 6, 7, 8}. It is a finite set with 5 elements.

💭 Common slip: “Between” excludes the endpoints. {3, 4, 5, 6, 7, 8, 9} would be “from 3 to 9, inclusive.”

Worked Example · Subsets

List every subset of {a, b, c}

1
Count first
The set has 3 elements, so it has 23 = 8 subsets.
2
List by size
∅; {a}, {b}, {c}; {a, b}, {a, c}, {b, c}; {a, b, c}
3
Check the count
1 + 3 + 3 + 1 = 8 subsets, matching 23.

💭 Common slip: Students often forget the two “edge” subsets. The empty set and the whole set are subsets of every set.

Worked Example · Complement, Intersection, Union

Let U = {1, 2, 3, …, 10}, A = {1, 2, 3, 4, 5}, and B = {2, 4, 6, 8, 10}. Find A′ ∩ B.

1
Complement first
A′ is everything in U not in A: {6, 7, 8, 9, 10}.
2
Then intersect with B
Keep only what is in both {6, 7, 8, 9, 10} and {2, 4, 6, 8, 10}.
3
Answer
A′ ∩ B = {6, 8, 10}

💭 Common slip: Do the complement before the intersection. A ∩ B = {2, 4} first, then a complement, gives a completely different set.

Your Turn — Guided Practice

Now you try, with me right here

Work each one, then tap your answer.

Question 1 — Which is a subset of {2, 4, 6, 8}?

Here's why: Every element of {4, 8} is in {2, 4, 6, 8}, so it is a subset. {4, 5} is not, because 5 is not in the set.

Question 2 — If M = {1, 3, 5} and N = {3, 5, 7}, what is M ∪ N?

Here's why: The union holds every element in either set, each listed once: {1, 3, 5, 7}. {3, 5} is the intersection, the overlap.

Why This Matters

Sets are how answers are written

From here on, solution sets, domains, and ranges are all sets. Interval notation in Chapter 1 is a shorthand for sets of real numbers, and the words “and” and “or” in inequalities are intersections and unions.

This shows up everywhere

  • Lesson 1.7 writes solutions of inequalities as intervals: sets of numbers.
  • Lesson 1.8 uses “or” (union) for |x| > a and “and” (intersection) for |x| < a.
  • Lesson 2.3 describes every function by its domain and range, both sets.

Mini Knowledge Test

Show what you know — 5 quick questions

Question 1
How many subsets does {w, x, y, z} have?
Here's why: A set with n elements has 2n subsets, and 24 = 16. 8 is 23, 4 counts only the one-element subsets, and 15 forgets the empty set.
Question 2
Let U = {a, b, c, d, e} and P = {a, c, e}. Find P′.
Here's why: P′ is everything in U that is not in P: {b, d}. {a, c, e} is P itself, U is the whole universal set, and ∅ would mean P = U.
Question 3
Write {x | x is an integer and −2 ≤ x < 3} in roster form.
Here's why: ≤ includes −2 and < leaves out 3, so the set is {−2, −1, 0, 1, 2}. The other choices include or leave out the wrong endpoint.
Question 4
If A = {2, 4, 6, 8} and B = {1, 2, 3, 4}, find A ∩ B.
Here's why: The intersection keeps only the elements in both sets: {2, 4}. {1, 2, 3, 4, 6, 8} is the union, and {6, 8} is the part of A that is not in B.
Question 5
Which statement is true?
Here's why: The empty set is a subset of every set. {1} is a set, so it is a subset of {1, 2}, not an element of it. 3 is an element, not a set, so it is written 3 ∈ {1, 2, 3}. {1, 2} has 2, which is not in {1}.
