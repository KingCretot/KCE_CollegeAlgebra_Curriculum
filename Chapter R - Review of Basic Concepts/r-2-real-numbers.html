Let's Begin

Every number has a family

Algebra is arithmetic with rules you can count on. Before solving equations, you need to know which kind of number you are working with and which moves are always allowed.

Today you'll classify numbers, evaluate expressions with the order of operations, name the properties of real numbers, and use absolute value to find distance.

By the end of today, you will be able to:

  • 1Classify numbers as natural, whole, integer, rational, irrational, or real
  • 2Evaluate expressions using the order of operations and exponents
  • 3Use the properties of real numbers, including the identity, inverse, and closure properties, and absolute value
  • 4Order real numbers, including negatives and fractions, on the number line

Vocabulary

The words for this lesson

Rational Number

A number that can be written as p/q with integers p and q, q ≠ 0. Its decimal ends or repeats.

💡Example: −3, 0.75 = 3/4, and 0.333… = 1/3 are all rational.
Irrational Number

A real number that is not rational. Its decimal never ends and never repeats.

💡Example: √2, π, and √7 are irrational. √9 = 3 is not.
Distributive Property

a(b + c) = ab + ac. Multiplication spreads over addition.

💡Example: 3(x + 4) = 3x + 12
Absolute Value

|a| is the distance from a to 0 on the number line, so it is never negative. The distance between a and b is |b − a|.

💡Example: |−7| = 7 and the distance from −2 to 5 is |5 − (−2)| = 7.

Vocabulary

Order and more properties of real numbers

Order on the Number Line

a < b means a lies to the left of b on the number line. a > b means a lies to the right of b.

💡Example: −5 < −2 because −5 is farther left. Among negatives, the one with the larger absolute value is smaller.
Identity Properties

a + 0 = a and a · 1 = a. Adding 0 or multiplying by 1 leaves a number unchanged. 0 is the additive identity and 1 is the multiplicative identity.

💡Example: −8 + 0 = −8 and (3/5) · 1 = 3/5.
Inverse Properties

a + (−a) = 0 and a · (1/a) = 1 for a ≠ 0. A number plus its opposite is 0; a number times its reciprocal is 1.

💡Example: 9 + (−9) = 0 and (2/3) · (3/2) = 1. The number 0 has no reciprocal.
Closure Properties

If a and b are real numbers, then a + b and ab are also real numbers. Adding or multiplying real numbers never takes you outside the real numbers.

💡Example: √2 + 5 and (−4)(π) are both real numbers.

How It Works

Order of operations

1
Parentheses
Work inside parentheses, brackets, and fraction bars first, innermost first.
2
Exponents
Evaluate powers next. −24 = −16, but (−2)4 = 16.
3
Multiply and divide
Left to right, whichever comes first.
4
Add and subtract
Left to right, whichever comes first.

💭 Notice: In −24 the exponent applies only to 2, then the negative is applied. Parentheses around −2 change the answer from −16 to 16.

Real-World Context

How far apart are two temperatures?

Absolute value measures distance without caring about direction. On a winter morning in Minneapolis the low was −8°F and the afternoon high was 17°F.

Example: The change is |17 − (−8)| = |25| = 25 degrees. Subtracting in the other order gives |−25|, the same 25. Distance never depends on order.

Worked Example · Classifying Numbers

Classify each number in {−5, 0, 2/3, √16, √5, 0.7}

1
Simplify first
√16 = 4, so it is a natural number in disguise.
2
Sort
Natural: 4 (√16). Whole: 0, 4. Integers: −5, 0, 4. Rational: −5, 0, 2/3, 4, 0.7.
3
The rest
Irrational: √5 only. Every number in the set is real.

💭 Common slip: A square root is not automatically irrational. Simplify it first: √16, √25, and √49 are all integers.

Worked Example · Order of Operations

Evaluate −32 + 4(6 − 8)3 ÷ 2

1
Parentheses
6 − 8 = −2, so the expression is −32 + 4(−2)3 ÷ 2
2
Exponents
−32 = −9 and (−2)3 = −8, giving −9 + 4(−8) ÷ 2
3
Multiply, divide, then add
4(−8) = −32; −32 ÷ 2 = −16; −9 + (−16) = −25

💭 Common slip: −32 is −9, not 9. The exponent belongs to the 3 alone because there are no parentheses around −3.

Worked Example · Order on the Number Line

Write 3/4, −2, −1/2, 1.2, −1.5 in order from least to greatest

Goal: Place each number on the number line. The farther left a number is, the smaller it is.

1
Write each as a decimal
3/4 = 0.75, −1/2 = −0.5. The others are already decimals: −2, 1.2, −1.5.
2
Order the negatives
−2 < −1.5 < −0.5. The larger the absolute value of a negative number, the farther left it sits.
3
Order the positives and combine
0.75 < 1.2, so the order is −2, −1.5, −1/2, 3/4, 1.2.
Number line from −3 to 2 with dots at −2, −1.5, −1/2, 3/4, and 1.2, in that order from left to right

💭 Common slip: −2 is not greater than −1.5 just because 2 > 1.5. On the number line, −2 is to the left, so −2 < −1.5.

Worked Example · Properties

Name the property used in each step: 5(x + 2) + 3x = 5x + 10 + 3x = 5x + 3x + 10 = 8x + 10

1
Step 1
5(x + 2) = 5x + 10 uses the distributive property.
2
Step 2
Swapping 10 and 3x uses the commutative property of addition.
3
Step 3
5x + 3x = (5 + 3)x = 8x uses the distributive property again, in reverse.

💭 Common slip: Commutative changes the order (a + b = b + a). Associative changes the grouping ((a + b) + c = a + (b + c)).

Your Turn — Guided Practice

Now you try, with me right here

Work each one, then tap your answer.

Question 1: Which number is irrational?

Here's why: √11 is not a perfect square, so its decimal never ends or repeats. √36 = 6 is an integer, which is rational.

Question 2: Evaluate (−4)2 − 42.

Here's why: (−4)2 = 16 and 42 = 16, so 16 − 16 = 0. 32 adds the two squares instead of subtracting them.

Question 3: Which statement is true?

Here's why: −7 is to the left of −3 on the number line, so −7 < −3. −7 > −3 compares 7 and 3 and forgets the negative signs. |−7| = 7 and |−3| = 3, and 7 is not less than 3.

Why This Matters

These rules are every algebra step

Every move you make when you simplify or solve, whether distributing, combining like terms, or moving a term, is one of these properties. Absolute value comes back as distance, and number sets come back as domains.

This shows up everywhere

  • Lesson R.3 uses the distributive property to multiply every polynomial.
  • Lesson 1.8 solves |x − a| = b by reading it as distance.
  • Lesson 2.1 uses |x2 − x1| for distances on the coordinate plane.

Mini Knowledge Test

Show what you know: 7 quick questions

Question 1
Evaluate 2 + 3 · 42 − 10 ÷ 5.
Here's why: 42 = 16; 3 · 16 = 48; 10 ÷ 5 = 2; 2 + 48 − 2 = 48. 78 adds 2 + 3 before multiplying, 144 squares 3 · 4 = 12 instead of squaring only the 4, and 46 drops the 2 at the front (3 · 16 − 2).
Question 2
Which set does −7/1 belong to?
Here's why: −7/1 = −7, an integer. Every integer is rational, and every rational number is real. It is negative, so it is not natural or whole.
Question 3
Which property is shown by (3 + x) + 5 = 3 + (x + 5)?
Here's why: Only the grouping changed, not the order, so it is associative. Commutative would swap the order, and distributive involves multiplying over a sum.
Question 4
Find the distance between −9 and 4 on the number line.
Here's why: |4 − (−9)| = |13| = 13. 5 is |4 + (−9)|, which adds instead of subtracting. A distance is never negative, and 36 multiplies.
Question 5
Evaluate −|−6| + |3 − 8|.
Here's why: −|−6| = −6 and |3 − 8| = |−5| = 5, so −6 + 5 = −1. 11 treats −|−6| as +6, 1 flips the sign of the final answer, and −11 subtracts the 5.
Question 6
Which list is in order from least to greatest?
Here's why: As decimals: −3/4 = −0.75, −1/2 = −0.5, 0.6, and 2/3 ≈ 0.667. So −0.75 < −0.5 < 0.6 < 0.667. The first list puts −1/2 before −3/4, but −3/4 is farther left. The second list runs from greatest to least. The third list puts 2/3 before 0.6, but 2/3 ≈ 0.667 is larger.
Question 7
Which property is shown by 7 + (−7) = 0?
Here's why: Adding a number and its opposite gives 0, the additive identity: that is the inverse property. The identity property would be 7 + 0 = 7. Closure only says the sum is a real number, and commutative would swap the order, as in 7 + (−7) = (−7) + 7.
