# KCE College Algebra

KCE-authored companion lessons for *Essentials of College Algebra*, 12th ed. (Lial, Hornsby, Schneider, Daniels; Pearson, ISBN 978-0134697024), for students in MAC 1105 College Algebra. Files follow the textbook's section numbers.

Scope: one chapter per textbook chapter, R through 5 (43 sections), each ending with a chapter review. All six chapters are live.
